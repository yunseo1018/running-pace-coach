# 예측 범위 보정 결과 (탐색 결과, 5km 과제)

생성: `scripts/55_interval_calibration_5km.py`. 사양: `docs/interval_calibration_spec_5km.md`(커밋 76b5922, 결과 계산 전 고정). 범위 규칙은 **train 안에서만** 정했고(사용자 단위 GroupKFold(5, seed 42), 폴드 밖 잔차), test는 이미 열람한 자료이므로 아래 test 결과는 **탐색 결과**이며 "검증됐다"고 쓰지 않는다. 주 결론(49c02f8)·모델·정의·분할·ŷ 계산식은 바꾸지 않았다. 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다. ID·행 값은 싣지 않았다.

## 1. 보정 규칙

| 항목 | 값 |
|---|---|
| 보정 자료 | train 평가 대상 1,720개·278명 |
| 폴드별 LAD 적합 a_f 범위(초) | -17.07 ~ -10.38 |
| 폴드별 LAD 적합 b_f 범위 | -0.8393 ~ -0.7405 |
| 폴드 밖 잔차 10%·90% 분위수 (q10_oof, q90_oof) | -202.1, 277.9초 (폭 480.0초) |
| 기존: 표본 내 잔차 10%·90% 분위수 (q10_ins, q90_ins) | -199.8, 276.5초 (폭 476.2초) |
| train 안 범위 안 비율: 보정 범위 / 기존 범위(폴드 밖 잔차 기준) / 기존 범위(표본 내 잔차 기준) | 80.0% / 79.7% / 80.0% |

시연의 ŷ = a + b·x는 train 전체 LAD 적합(a = -15.287초, b = -0.7912)으로 그대로다. 폴드별 a_f·b_f는 폴드 밖 잔차에만 썼다.

- 포함률(풀링) = 정답 y가 범위 안에 들어간 평가 대상의 비율. 95% CI는 사용자 단위 bootstrap(사용자 복원추출 2,000회, seed 42, 백분위 CI, 모든 범위·조건에 같은 추출)이다. 평균 폭은 q90 − q10으로 모든 예측에 같다.
- ŷ는 두 조건 모두 시연의 B2(cold-start train 적합)로 계산했다. **personalized 평가 행은 학습 자료와 겹쳐 독립 평가가 아니다**: 442건 중 364건이 시연의 a·b와 범위를 만든 train 평가 대상 1,720건에 그대로 들어 있다(`docs/interval_by_condition.md` 4절). 그래서 personalized 포함률은 이 표에서 주 결과로 싣지 않는다("-" 표시, 계산하지 않은 것이 아니라 보고하지 않는 것이며 새로 계산하지도 않았다).

## 3. 해석 (사양 3절의 규칙)

- cold-start test, 기존(표본 내 잔차): 포함률 73.9% [66.3%, 79.7%] → **명목 80%보다 낮음**.
- cold-start test, 보정(폴드 밖 잔차): 포함률 75.3% [68.2%, 81.0%] → **명목 80%에서 벗어났다고 확정할 수 없음**.
- personalized, 기존(표본 내 잔차): 독립 평가 아님(학습 자료와 겹침, 364/442건 중복) → 해석하지 않는다.
- personalized, 보정(폴드 밖 잔차): 독립 평가 아님(학습 자료와 겹침, 364/442건 중복) → 해석하지 않는다.

- 보정 범위는 기존 범위보다 폭이 3.8초 넓다. 포함률은 cold-start test에서 75.3%(기존 73.9%)이다(점추정). 폭과 포함률의 이 교환은 구성상의 것이며 범위가 개별 예측의 정확성을 뜻하지 않는다. 개인에게 80%를 보장한다고 쓰지 않는다.
- 사용자별 포함률은 평가 대상이 1개뿐인 사용자에서 0% 또는 100%가 되므로 분포의 해석에 한계가 있다(특히 personalized). test 결과는 이미 열람한 자료의 탐색 결과다.
- **시연은 이 결과와 상관없이 보정 범위를 쓴다**(사양 1·4절): "명목 80% 범위", "테스트 포함률 75.3%(탐색 결과), 개인에게 80%를 보장하지 않음"(보정 범위의 cold-start test 포함률).
- 이 결과로 주 결론, 모델, 정의, 분할, ŷ의 계산식을 바꾸지 않는다.
