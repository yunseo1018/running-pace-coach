- GPS 이상치 여부: 세션 단위로 별도 플래그가 파이프라인에 없어 (01단계에서 포인트 단위로 이미 필터링됨) **측정하지 않음 (미확인)**

**해석**: RMSE는 상위 1% 윈도우가 SSE의 90% 이상을 차지하는 극단 윈도우 민감 지표다 — 평균적인 체감 오차를 보려면 MAE를, 소수의 큰 실패가 전체 지표를 얼마나 흔드는지 보려면 RMSE를 같이 봐야 한다.

## E. 확인 메모
- 순위 비교는 반드시 MAE/RMSE를 각각 따로 서술한다 (아래 요약 텍스트 참고).
- 원인이 확인되지 않은 패턴은 모두 '추정/미확인'으로 표기했다.
