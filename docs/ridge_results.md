## 3. 하이퍼파라미터(alpha) 선택
- **선택 기준**: 각 alpha 후보에 대해 계산한 **평균 CV MAE(절대오차 평균)를 최소화하는 alpha**를 선택한다 (RMSE 기준 선택은 하지 않음 — MAE가 선택 지표).
- **최초 후보 격자**: [0.01, 0.1, 1.0, 10.0, 100.0, 1000.0] (로그 간격). 이 격자로 처음 돌렸을 때 cold-start/personalized 선택이 **격자 하한(0.01)**에, post-hoc(7번) 선택이 **격자 상한(1000.0)**에 걸렸다 — 둘 다 범위 안에서 내부 최솟값이 아니라 경계에서 끝났다는 뜻이라, 두 방향 모두 격자를 넓혀 재검증했다.
- **넓힌 후보 격자(최종 사용)**: [0.0001, 0.001, 0.01, 0.1, 1.0, 10.0, 100.0, 1000.0, 10000.0, 100000.0]
- **cold-start**: train 사용자만으로 **사용자 단위 GroupKFold(5-fold, seed=42)**를 train 내부에서 돌려 평균 CV MAE가 가장 작은 alpha를 선택. test는 전혀 사용하지 않음.
  - 선택된 alpha = **0.0001** (여전히 격자 하한)
  - alpha별 평균 CV MAE: 0.0001=60.485623, 0.001=60.485623, 0.01=60.485623, 0.1=60.485624, 1.0=60.485636, 10.0=60.485750, 100.0=60.486907, 1000.0=60.499951, 10000.0=60.727316, 100000.0=63.806691
  - **넓힌 뒤 바뀐 점 확인**: 선택된 alpha는 0.01→0.0001로 바뀌었지만, alpha=0.01일 때와 alpha=0.0001일 때 최종 test MAE/RMSE는 **소수점 6자리까지 동일**(69.928493/262.069142, 직접 재계산해 확인)했다. 즉 **이 alpha 범위에서 정규화 강도가 예측 결과에 미치는 영향이 사실상 없다** — 메인 통합표(4번) 수치는 바뀌지 않으므로 갱신하지 않는다.
- **personalized**: 각 사용자의 history 구간을 다시 시간순 앞 80%(inner-train)/뒤 20%(inner-val)으로 나눠(06단계의 history/hold-out 분할과 동일한 방식을 history 내부에 재귀 적용) inner-val MAE가 가장 작은 alpha를 선택. 실제 holdout(test)은 전혀 사용하지 않음. (간단한 1회 시간순 분할이며, 여러 번 반복하는 완전한 시계열 CV는 아님 — 범위상 간소화했다.)
  - 선택된 alpha = **0.0001** (여전히 격자 하한)
  - alpha별 inner-val MAE: 0.0001=62.220278, 0.001=62.220278, 0.01=62.220278, 0.1=62.220283, 1.0=62.220325, 10.0=62.220749, 100.0=62.225012, 1000.0=62.268254, 10000.0=62.724264, 100000.0=66.643663
  - **넓힌 뒤 바뀐 점 확인**: 선택된 alpha는 0.01→0.0001로 바뀌었지만, alpha=0.01일 때와 alpha=0.0001일 때 최종 test MAE/RMSE는 **소수점 6자리까지 동일**(62.053868/239.761552~239.761553, 직접 재계산해 확인)했다. 메인 통합표(4번) 수치는 바뀌지 않으므로 갱신하지 않는다.

## 7. [POST-HOC 분석, 타깃 실제 거리 입력 포함 — 사전 예측 성능 아님] Ridge
**주의: 이 표는 타깃 세션의 실제 완주 거리를 입력(X)에 추가한 Ridge다. 러닝 전에는 알 수 없는 사후 정보를 쓰므로 예측 성능으로 보고하지 않으며, 메인 표(4번)와 절대 섞지 않는다.**

- **평가 조건: cold-start 분할** (post-hoc은 personalized 버전을 만들지 않았음 — train/test는 04단계와 같은 cold-start 사용자 분할).
- alpha 선택(GroupKFold, train 내부, [0.01, 0.1, 1.0, 10.0, 100.0, 1000.0]로 처음 돌렸을 때 상한(1000.0)에 걸려 [0.0001, 0.001, 0.01, 0.1, 1.0, 10.0, 100.0, 1000.0, 10000.0, 100000.0]로 넓혀 재검증): **10000.0** (격자 경계 아님(내부 최솟값, 양옆 값 모두 더 나쁨)) (CV MAE: 0.0001=62.446019, 0.001=62.446019, 0.01=62.446018, 0.1=62.446011, 1.0=62.445938, 10.0=62.445212, 100.0=62.437989, 1000.0=62.369562, 10000.0=61.967192, 100000.0=63.680421)
- **[사후 거리 조건 분석] MAE=72.270, RMSE=261.471** (cold-start 분할 기준, n=21978)
- **타깃 실제 거리(표준화) 계수 = -18.688** (16개 피처 중 마지막, 나머지 15개는 과거 세션 피처). 부호가 **음수** — 표준화된 피처 기준, 다른 입력을 고정했을 때 타깃 거리가 길수록 모델이 예측하는 페이스(초/km) 값이 **낮아지는(빨라지는) 쪽으로 선형 관계를 적합했다**는 뜻이다. 이 선형 계수의 방향이 실제 원인(예: 짧고 빠른 인터벌/대회 세션이 길고 느린 세션보다 많이 섞여 있어서 생긴 상관인지, 다른 이유인지)은 **미확인**이다 — 인과관계로 해석하지 않는다.
- **메인 Ridge(과거 기록만, cold-start) MAE=69.928, RMSE=262.069인데, 타깃의 실제 거리를 입력에 추가한 post-hoc Ridge는 오히려 MAE가 72.270로 더 나쁘다(+2.341).** RMSE는 261.471로 메인보다 소폭 나쁘다(-0.598). **거리라는 사후 정보를 추가했는데 왜 MAE가 악화되는지는 확인된 원인이 없다 (미확인)** — 가능한 추정(검증 안 함): 16차원으로 늘면서 train 내부 GroupKFold가 더 큰 alpha(정규화)를 선택해 다른 15개 피처의 유효 계수가 전반적으로 축소됐을 수 있다, 또는 거리와 기존 피처(과거 거리/페이스) 간 상관이 겹쳐 선형모델이 안정적으로 분리해 쓰지 못했을 수 있다. 둘 다 이번 분석에서 직접 검증하지 않았다.

## 9. 해석
**RMSE는 상위 1% 윈도우가 SSE의 대부분을 차지하는 극단 윈도우 민감 지표다** (8-6 참고, 90% 안팎). 이 전제 위에서 MAE 기준과 RMSE 기준 결론이 다르므로 각각 따로 쓴다.

- **MAE 기준**: Ridge는 cold-start/personalized 둘 다 median-5보다 **통계적으로 유의하게 나쁘다** (윈도우 풀링 MAE 기준, macro는 이 문서에서 미계산; 95% CI가 0을 포함하지 않고 median-5가 더 작은 쪽).
- **RMSE 기준**: Ridge는 median-5·사용자 전체 평균과는 **통계적으로 구분되지 않는다**(CI가 0을 포함) — 즉 '이겼다'고 할 수 없고 '동률'이다. 다만 최근 5회 평균보다는 **유의하게 낫다**.

## 10. 한계
**personalized의 전역 모델 시점 혼입 가능성 (영향은 미확인)**: personalized Ridge는 모든 사용자의 history를 한 번에 풀링해 **하나의 전역 모델**을 학습한다. 이 말은, 사용자 A의 평가 시점(hold-out)보다 **달력상 더 늦은 시기**에 기록된 사용자 B의 history 윈도우가 같은 학습 데이터에 섞여 들어갈 수 있다는 뜻이다 — 각 사용자 자신의 과거만 보는 것은 보장되지만(04/06단계 감사 참고), '전역 모델 파라미터'는 다른 사용자의 더 늦은 시기 정보로부터 영향을 받을 수 있다. 이게 실제로 성능에 얼마나 영향을 주는지는 **검증하지 않았다 (미확인)** — 사용자별로 완전히 분리된 모델을 쓰거나 시점을 엄격히 맞춘 글로벌 분할을 쓰면 다른 결과가 나올 수 있다.

## 11. Ridge가 최고 baseline을 이겼는가 — plain 판정
**MAE 기준: Ridge는 최고 baseline(median-5)을 신뢰구간 밖에서 이기지 못했다.** 오히려 median-5가 Ridge보다 유의하게 낫다(윈도우 풀링 MAE 기준). **RMSE 기준: Ridge는 최고 baseline 그룹(median-5/사용자 전체 평균)을 신뢰구간 밖에서 이기지 못했다** — 동률일 뿐이다.

**이유는 추정/미확인이다.** 가능한 설명(모두 검증하지 않은 추정): (1) 입력 피처가 과거 5개 세션의 거리/페이스/심박만이라 선형모델이 활용할 수 있는 정보량 자체가 median-5(비선형적 극단치 저항성을 가진 통계량)보다 불리할 수 있다, (2) alpha 선택 결과가 전부 0.01(거의 무정규화)에 가까워 정규화가 과적합을 막는 데 별 역할을 못했을 수 있다, (3) 15차원 입력 자체가 선형 관계로 다음 페이스를 설명하기엔 부족할 수 있다. 어느 쪽이 실제 원인인지는 이번 분석에서 확인하지 않았다.
