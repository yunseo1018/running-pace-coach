## 1. 통계 방법 (모든 표 공통)
- cold-start: 평가 사용자 149명, 평가 윈도우 21977건, 타깃 페이스 중앙값 333.3초/km
- personalized: 평가 사용자 742명, 평가 윈도우 20628건, 타깃 페이스 중앙값 341.0초/km
- **재표집**: 평가 사용자를 복원추출(사용자 수만큼), 2000회, seed 42. 뽑힌 사용자의 **모든 윈도우**를 함께 쓰고 모든 방법에 같은 추출을 적용(쌍체). 95% CI는 percentile.
- **풀링 MAE**: 윈도우 단위 평균(사용자 윈도우 수에 비례해 가중). **macro MAE**: 사용자별 MAE의 평균(사용자 1명 = 1표, 뽑힌 사용자는 중복 횟수만큼 가중). 둘은 다른 양이며 둘 다 보고한다. RMSE는 풀링만.
- 쌍 차이 = (앞 방법) − (뒤 방법). **양수면 뒤 방법이 더 낮은(좋은) 값.** CI가 0을 포함하면 'CI가 0을 포함 — 동등성(차이가 없음)의 입증이 아님'이다. 다중 비교 보정은 하지 않았다(쌍이 다수이므로 개별 CI를 확정 근거로 쓰지 않음).
- 개선폭은 분모를 구분한다: (1) 절대 개선(초/km), (2) 그룹 기준 방법의 MAE 대비 %, (3) 평가 윈도우 타깃 페이스 중앙값 대비 %.
