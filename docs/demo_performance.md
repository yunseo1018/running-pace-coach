# 데모 성능 측정 (PC CPU, 서버·모바일 아님)

생성: `demo/bench_demo.py`. 시연은 B2(평균 회귀)만 사용한다. GBM·MLP는 비교 참고용이다(49c02f8과 같은 설정으로 cold-start 학습 자료에 다시 학습; 정확도 비교가 아님). 합성 예시 `demo/examples/ex2_slower_last.csv` 사용.

## 환경

- CPU: Intel(R) Core(TM) Ultra 9 275HX
- OS: Windows-11-10.0.26200-SP0
- Python: 3.14.7
- numpy 2.5.3, torch 2.14.0+cpu, torch 스레드 4
- 측정 방법: 예측 1회를 1000번 반복(워밍업 50회 제외), `time.perf_counter_ns`. 메모리 = `tracemalloc` 최대값(파이썬 힙만; torch 네이티브 메모리·인터프리터 기본 메모리는 포함되지 않음).

## 예측 1회 (1000회 반복)

| 대상 | 중앙값(ms) | 90% 분위(ms) | 최대(ms) | tracemalloc 최대(바이트) | 크기(바이트) |
|---|---|---|---|---|---|
| B2 데모: 자격 판정·예측·문구·숫자 검사(CSV 읽기 제외) | 0.0241 | 0.0281 | 0.1055 | 2,331 | 365 |
| B2 데모: 위 + CSV 파일 읽기·파싱 | 0.2820 | 0.4767 | 1.1460 | 160,301 | 365 |
| B2 식만 (a + b·x) | 0.0001 | 0.0002 | 0.0004 | 0 | 365 |
| GBM 예측 1행 (기본 입력 11, 참고) | 2.9802 | 4.2215 | 9.5302 | 126,089 | 87,889 |
| MLP 예측 1행 (기본 입력 11, 참고) | 0.0474 | 0.0676 | 0.6826 | 2,944 | 22,917 |

- 크기: B2 = `demo/b2_params.json` 파일 크기. GBM = pickle 직렬화 크기. MLP = `state_dict` 직렬화 + 스케일러 배열 크기(파라미터 4,993개, 배포용 최적화·양자화 없음). 표의 크기 열은 대상 행이 아니라 해당 모델의 크기이며 B2 세 행은 같은 값이다.
- 프로세스 시작을 포함한 `python demo/coach_demo.py ...` 한 번 실행(5회) 벽시계 시간: 최소 95 ms, 중앙값 101 ms, 최대 107 ms (인터프리터 시작 시간이 대부분).
- 이 수치는 이 PC 한 대에서의 값이며 다른 기기·모바일에는 일반화할 수 없다. 모바일·온디바이스(INT8 포함) 측정은 하지 않았다(미측정).
- 값의 변동: 같은 명령을 다시 실행하면 중앙값이 달라질 수 있다(다른 프로세스·전원 상태에 따라).
