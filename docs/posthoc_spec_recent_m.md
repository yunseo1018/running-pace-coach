# 사후 탐색 사양: 최근 기간 기준치 B2r (결과 계산 전 고정)

작성: 11월 2주차. **이 문서를 만드는 시점에 B2r의 결과(MAE, 차이, 포함률)는 계산하지 않았다.** 주 결론(49c02f8)·B2 시연(식·파라미터)·명목 80% 범위·조건별 안내 규칙은 바꾸지 않는다. 이 탐색의 결과는 어떤 경우에도 시연과 기존 결론을 바꾸는 근거로 쓰지 않으며, 개선돼 보여도 "향후 과제"로만 적는다.

- 분류: **사후 탐색**(탐색 결과). 시각은 start_time 원값(기준 미확인)이며 상관관계까지만 주장한다. 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다.
- 동기: B2의 m은 t 이전 **전체 기간**의 유효 5km 중앙값이라 오래된 기록이 섞인다. 최근 기간만 쓰면 달라지는지 본다.

## 1. 정의

- B2(기존): ŷ = a + b·(T5(기준) − m), m = t 이전에 끝난 모든 유효 5km의 T5 중앙값(1개뿐이면 m = T5(기준)). 변경 없음.
- **B2r**: 같은 식이되 m 대신 **m_W** = t 이전에 끝난(종료 시각 ∈ [t − W일, t)) 유효 5km(비병합 5.0~5.5km, 극단 T5 > 5,000초 제외)의 T5 중앙값. a·b는 B2r 자신의 x_r = T5(기준) − m_W로 LAD 적합한다. 기준 기록은 항상 직전 28일 안에 있으므로 W ≥ 28이면 최근 기록 수 n_W ≥ 1이다.
- 후보: W ∈ {90, 180, 365}일 × 최소 기록 수 k ∈ {1, 2, 3} = **9개 후보**. n_W < k일 때의 규칙 두 가지: **(대체)** 기존 전체 기간 m을 쓴다 / **(보류)** 예측하지 않는다. (W, k, 규칙) 조합은 18개다.
- 예측 시점에 관측 가능한 값만 쓴다(종료 시각 < t인 기록의 T5, 정답 값은 쓰지 않음).

## 2. 선택 절차 (개발 자료만; test는 선택에 쓰지 않는다)

- 자료: train 평가 대상 1,720개·278명(`data/5km_dataset_train.pkl`과 같은 행). 사용자 단위 GroupKFold(5, seed 42, `ridge_lib.group_kfold_indices`, 범위 보정 55번과 같은 분할). **각 폴드의 학습 부분에서 a·b를 다시 적합**(B2는 x로, B2r은 x_r로 각각 LAD)하고 폴드 밖 행을 예측한다.
- **선택 점수**: 후보 (W, k)마다 **두 규칙이 모두 예측하는 행**(n_W ≥ k)에서 사용자별 (B2r MAE − B2 MAE)의 평균(사용자 평균 MAE의 쌍별 차이, 낮을수록 좋음). 행 집합이 후보마다 달라 원 MAE는 후보 사이에서 비교할 수 없으므로 같은 행의 B2와의 차이로 비교한다. 이 행에서 대체와 보류의 예측은 같으므로 규칙은 점수로 구별되지 않는다 → **동률이면 (대체)**를 택한다(예측 가능 시점을 줄이지 않는 쪽). 보류 규칙의 예측 가능 비율과 대체 규칙의 전체 행 점수는 선택 과정 공개용으로 표에 함께 싣는다.
- 가장 낮은 점수의 (W, k, 규칙) **하나**를 선택하고 결과를 본 뒤 후보·규칙·점수 정의를 바꾸지 않는다.

## 3. 선택된 설정의 평가와 보고 (train 폴드 밖 = 개발, test cold-start = 탐색·이미 열람, 나란히)

- test: 352개·71명. B2r의 a·b는 train 1,720개 전체에서 적합(보류 규칙이면 예측 행만), B2는 시연의 a·b(train 전체 LAD)다. **test 결과는 선택에 쓰지 않았고 이미 열람한 자료의 탐색 결과다.**
- **명목 80% 범위**: B2r의 범위는 범위 보정(55번)과 같은 절차로 B2r 자신의 **폴드 밖 잔차**의 10%·90% 분위수(q10, q90)를 ŷ_r에 더해 정한다. B2는 기존 범위(시연)를 그대로 쓴다.
- 보고 항목:
  - (a) B2r과 B2가 **둘 다 예측한 같은 시점**에서 사용자별 (B2r MAE − B2 MAE)의 평균과 사용자 단위 bootstrap 95% CI(주; 사용자 복원추출 2,000회, seed 42, 백분위 CI), 중앙값("사용자별 오차 차이 중앙값 기준", 보조), 사용자 수.
  - (b) 예측 가능 시점 비율(B2 대비): 선택된 규칙과 다른 규칙 둘 다.
  - (c) 각자(B2, B2r)의 명목 80% 범위 포함률(사용자 단위 bootstrap 95% CI), 평균 폭, 관측 수·사용자 수.
  - (d) 9개 후보 전체의 개발 자료 표(선택 과정 공개): 후보마다 두 규칙의 예측 행 수·비율, 같은 행에서의 B2r·B2 사용자 평균 MAE와 차이(선택 점수), 대체 규칙의 전체 행 사용자 평균 MAE 차이.
- 검증(assert): B2의 폴드 밖 잔차 분위수가 `demo/b2_params.json`과 같음, B2 train 전체 적합 a·b가 49c02f8과 같음, B2 test 예측이 저장된 49c02f8 예측과 같음, 전체 기간 m 재계산이 데이터셋의 m과 같음.

## 4. 해석 규칙 (미리 고정)

- 주 판정은 (a)의 평균 차이 CI로만 낸다. **CI가 0을 포함하면 "우열 확정 불가(동등성 입증 아님)"**, 하한이 0보다 크면 "B2r이 B2보다 나쁨", 상한이 0보다 작으면 "B2r이 B2보다 좋음"(개발·탐색 각각). 중앙값·비율은 보조다.
- **후보를 9개(규칙 포함 18개 조합) 보고 하나를 골랐으므로 선택된 설정의 개발 자료 개선은 선택 편향으로 우연일 수 있다**(개발 점수는 낙관적). test는 선택에 쓰지 않았지만 이미 열람한 자료의 탐색 결과다.
- 개선돼 보여도 시연(B2, 범위, 안내)과 기존 결론(49c02f8)을 바꾸지 않는다. 향후 과제로만 적는다. 새 자료로의 확인이 필요하다.
- 포함률의 CI가 80%를 포함하면 "명목 80%에서 벗어났다고 확정할 수 없음"이다.
