### 0-2. 모델명 표기 정정
이전 보고서/CLAUDE.md에서 'HGB'라고 썼던 표기를 전부 **'직접 구현 GBM(gbt_lib)'**으로 고친다 — sklearn의 HistGradientBoostingRegressor는 이 환경에서 한 번도 실행되지 않았고(0-1 참고), 전부 `gbt_lib.SimpleGradientBoostingRegressor`(numpy 직접구현) 결과다. sklearn 구현과 다를 수 있는 점(코드 기준 확인):
- **분할 탐색**: `gbt_lib.py` 204행 `g = np.sign(residual) if loss=="absolute_error" else residual` — absolute_error에서는 **부호(sign)만 있는 pseudo-residual**로 분할 지점을 고른다(제곱오차 감소량 기준).
- **리프 값 갱신**: `gbt_lib.py` 189-193행에서 `leaf_agg = np.median`(absolute_error) 또는 `np.mean`(squared_error)로 정하고, 126/131/138행에서 `node.value = leaf_agg(residual_actual[row_idx])`로 **실제 residual의 중앙값(또는 평균)**을 리프 값으로 쓴다 — **부호만 쓰는 게 아니라 Friedman TreeBoost 방식의 리프값 보정을 실제로 한다.** sklearn의 `max_leaf_nodes`(best-first 확장), L2 정규화, 2차 근사 기반 분할 이득(뉴턴 스텝)은 구현하지 않았다(`max_depth` 기반 완전이진트리로 대체, 0-1 참고).

### 1-1. 6단계(Ridge) 통합표의 median-5 수치와 다른 이유
6단계 median-5 MAE(62.217 cold-start / 56.446 personalized)와 이번 7단계 통합표(아래 3번, 62.219 / 56.449)가 소수점 세 자리에서 다르다. 원인을 윈도우 단위로 직접 대조했다(`(user_id, window_start_session_order)` 키로 집합 비교):

| personalized hold-out | 20629 | 20628 | 1 | 0 |
제외 사유: 7단계에서 추가한 `user_history_median_pace` 피처 때문에 last_input_session_time 감사와 같은 방식의 **이력 감사**(그 피처가 참조하는 가장 늦은 세션 종료 시각이 타깃 시작 시각보다 앞서는지)를 새로 적용했고, 이걸 통과 못 한 윈도우를 추가로 제외했다(6단계는 이 피처가 없어서 이 감사 자체가 없었다).

personalized는 '제외 3 / 추가 1'로 숫자가 안 맞는 것처럼 보이는데, 실제로는 **사용자 8349084의 history 윈도우 2개(session_order 126,127)가 이력 감사로 빠지면서 그 사용자의 전체 유효 윈도우 수가 줄어 history/hold-out 80% 경계가 한 칸 당겨졌고, 원래 hold-out 첫 윈도우였던 session_order 178이 history 쪽으로 넘어간 것**이다 (직접 대조로 확인). 버그가 아니라 '감사 제외 -> 사용자별 윈도우 수 변화 -> 80% 경계 재계산'이 순서대로 일어난 결과다.
**이번 7단계 보고서의 모든 비교(median-5 vs 신규 모델)는 7단계 윈도우 집합(위 표의 '7단계 윈도우 수')에서 똑같이 계산한 값이다** — 6단계 수치와 섞어서 비교하지 않는다.

## 5. 해석
- **cold-start**: CV기준 선택 모델(7a. 직접구현 GBM(absolute_error), 주 결과)이 median-5를 MAE 신뢰구간 밖에서 **이겼다** (median5-이모델 diff 95% CI [1.579,3.496], 0 미포함).

**RMSE 결론이 MAE 결론과 다를 수 있음에 유의**: RMSE는 상위 1% 오차 윈도우가 SSE 대부분을 차지하는 극단 민감 지표라(위 세분화 참고), MAE에서 진 방법이 RMSE에서는 통계적으로 구분되지 않을 수 있다 — 위 쌍체 차이 표의 RMSE 열을 MAE 결론과 섞지 말고 따로 읽는다.

이긴 조건이 있으므로 사용자 확인 후 다음 단계(MLP) 진행 여부를 논의한다.

### (b) 합성 비대칭(두꺼운 꼬리) 노이즈 테스트
- Exponential(비대칭) 노이즈(평균=0, 중앙값≈-13.86)를 더한 2개 그룹 합성 데이터:
- 그룹0(실제 조건부 중앙값=93.82, 평균=100.00): absolute_error 예측=93.31(중앙값에 더 가까움=True), squared_error 예측=99.85(평균에 더 가까움=True)
- 그룹1(실제 조건부 중앙값=43.86, 평균=50.00): absolute_error 예측=44.03(중앙값에 더 가까움=True), squared_error 예측=50.28(평균에 더 가까움=True)
- **확인됨**: absolute_error는 조건부 중앙값 쪽, squared_error는 조건부 평균 쪽으로 수렴한다 — 둘 다 설계대로 동작.
