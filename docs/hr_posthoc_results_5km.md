# 사후 탐색 결과: 기준 기록 세션의 상대 심박 (5km 과제)

생성: `scripts/47_hr_posthoc_5km.py`. 사양: `docs/posthoc_spec_hr_5km.md`(커밋 9d2efda, 분석 실행 전 고정). 이 문서의 구성은 사양 4절의 보고 항목 순서를 따른다. **사후 탐색**(test 정답을 본 뒤의 분석)이며 상관관계까지만 주장하고 인과·처방 해석을 하지 않는다. **freeze-5km-v1 결과(`docs/final_results_5km.md`, 49c02f8)와 시연 예측식(`demo/b2_params.json`, `demo/coach_demo.py`)은 바꾸지 않았고, 이 결과를 시연이나 최종 평가에 반영하지 않는다.** 시각은 start_time 원값(기준 미확인)이다. ID·행 단위 값은 싣지 않았다. 주 분석 데이터셋이 49c02f8의 평가 행(cold test 352개, personalized 442개)과 일치함을 assert로 확인했다.

정의(사양 1·6절): h_base = 기준 기록 세션 `avg_heart_rate`(30~230bpm 유효 점 평균, 세션 전체), h_ref = t 이전에 끝난 본인의 유효 5km 세션(비병합 5.0~5.5km, T5 ≤ 5,000초, 기준 기록 제외) `avg_heart_rate`의 중앙값, r = h_base − h_ref(bpm). 모형에는 r10 = r/10을 넣어 계수를 +10bpm당 값으로 보고한다.

## 4. CI가 0을 포함하는지와 읽는 법 (사양 5절의 해석 규칙)

- CI가 0을 포함하면 **"관계를 확인하지 못함"**이라고 쓴다. 관계가 없다는 증명(동등성)이 아니다.
- CI가 0을 포함하지 않아도 **상관이며 인과가 아니다**. 평균 심박은 기온·컨디션·센서·훈련 강도 등과 얽힐 수 있으며 이 중 어느 것도 확인하지 않았다(미확인).
- 모델이 둘이고 계수가 여럿이므로 우연히 CI가 0을 벗어나는 계수가 생길 수 있다. 결과를 보고 모형·정의·범위를 바꾸지 않았다.

주 모형:
- (T5(기준) − m) 1초당: CI가 0을 포함하지 않지만 **상관이며 인과가 아니다**.
- r10: r이 +10bpm 클 때: CI가 0을 포함하므로 **관계를 확인하지 못함**(관계가 없다는 증명이 아니다).

보조 모형:
- (T5(기준) − m) 1초당: CI가 0을 포함하지 않지만 **상관이며 인과가 아니다**.
- r10: r이 +10bpm 클 때: CI가 0을 포함하므로 **관계를 확인하지 못함**(관계가 없다는 증명이 아니다).
- (T5(기준) − m) × r10: r이 +10bpm 클 때 γ의 변화(1초당): CI가 0을 포함하므로 **관계를 확인하지 못함**(관계가 없다는 증명이 아니다).

한계: h_base는 세션 전체 평균 심박이며 처음 5km 구간의 평균이 아니다(사양 6.4). T5(기준) − m의 계수 γ는 기준 기록의 상대 위치와 변화량의 관계이며 훈련 효과로 해석하지 않는다.
