# 사후 분석 사양: B2가 흔들리는 지점(층별 점검) (분석 실행 전 고정)

작성: 11월 1주차. **이 문서를 만드는 시점에 층별 결과(MAE, 차이, 포함률)는 계산하지 않았다.** 주 결론(49c02f8)·모델·정의·분할·시연의 B2 식·파라미터·범위는 바꾸지 않는다.

- 분류: **사후 분석**. 층 경계와 층 정의는 결과를 본 뒤 바꾸지 않는다. 상관관계까지만 주장하며 인과·처방 표현을 쓰지 않는다. "start_time 원값(기준 미확인)", "관측된 러닝 기록의 공백". 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다. ID·행 값은 출력·저장하지 않는다.
- 목적: B2(평균 회귀 규칙)와 명목 80% 범위가 **어떤 층에서 더 흔들리는지** 본다. 이 결과로 시연 규칙(식, 파라미터, 범위, 문구)을 바꾸지 않는다.

## 1. 자료

- **규칙을 정하는 자료 = train**: 평가 대상 1,720개·278명. 사용자 단위 GroupKFold(5, seed 42)(`ridge_lib.group_kfold_indices`, `docs/interval_calibration_spec_5km.md`와 같은 분할)의 **폴드 밖** B2 예측과 잔차. 폴드마다 학습 폴드에서 B2(a_f, b_f)를 LAD로 적합하고 폴드 밖 평가 대상의 ŷ_oof = a_f + b_f·x를 만든다(x = T5(기준) − m).
- **test cold-start(352개·71명)**는 같은 표에 함께 보고하되 **"탐색 결과(이미 열람)"**로 표기한다. test의 ŷ는 시연의 B2(train 전체 LAD 적합 a, b)다. 이 분석의 결과로 test를 이용해 규칙을 정하지 않는다.
- B0 = ŷ 0(변화 없음). B2는 위의 ŷ.
- **명목 80% 범위** = ŷ + [q10_oof, q90_oof](시연이 쓰는 보정 범위; train 폴드 밖 잔차의 10%·90% 분위수, `docs/interval_calibration_5km.md`). train 행의 포함률은 y가 ŷ_oof + [q10_oof, q90_oof]에 들어간 비율이다(구성상 전체로는 약 80%).

## 2. 층 (모두 예측 시점에 관측 가능한 값만 사용, 각 차원에서 모든 평가 대상이 정확히 한 층에 들어감)

| 차원 | 정의 | 층 |
|---|---|---|
| (a) 과거 유효 5km 개수 | m을 만드는 과거 5km 후보 수(기준 기록 포함; `docs/m_construction_5km.md`의 `past` 크기) | 1개(x = 0) / 2~4개 / 5개 이상 |
| (b) \|T5(기준) − m\| | 초 | 0초(정확히 0) / 0초 초과 ~ 30초 이하 / 30초 초과 ~ 120초 이하 / 120초 초과 |
| (c) 기준 기록이 t보다 며칠 전인지 | (t − 기준 기록 세션의 종료 시각) / 86,400초 | [0, 7)일 / [7, 14)일 / [14, 28]일 |
| (d) 직전 28일 달리기 횟수 | 입력 창 [t−28일, t)에 끝난 세션 수(병합 세션 1회) | 4~7회 / 8~15회 / 16회 이상 |
| (e) 기준 기록 세션 안의 정지 시간 | 기준 기록 세션 점 기록에서 시간차 > 0이고 속도 1km/h 미만인 점 사이 구간의 시간 합(초, 세션 전체) | 0~60초(60 포함) / 60초 초과 ~ 300초 이하 / 300초 초과 |

(b)·(e)의 경계는 위 괄호 표기대로다(위쪽 포함). (a)의 "1개"는 x = 0이 되는 사전 선언 규칙(m = 기준 기록)에 해당한다. 층 경계는 결과를 보고 바꾸지 않는다.

## 3. 층마다 보고하는 값 (train 폴드 밖 / test cold-start 각각)

1. 평가 대상 수, 사용자 수(그 층에 평가 대상이 있는 사용자).
2. **B2 사용자 평균 MAE**, **B0 사용자 평균 MAE**(층 안에서 사용자별 평균 절대 오차를 구한 뒤 사용자 평균), **차이(B2 − B0)**(음수 = B2 쪽 오차가 작음).
3. **명목 80% 범위 포함률**(층 안 풀링).
4. **사용자 단위 bootstrap 95% CI**: (B2 − B0) 차이와 포함률. **2,000회, seed 42**, 층마다 **그 층의 사용자**를 복원추출(추출 크기 = 그 층의 사용자 수, `np.random.default_rng(42)`을 층·자료마다 새로 시작), 뽑힌 사용자의 층 안 평가 대상 전체 유지, 백분위 95% CI. 한 층에서 B2와 B0, 차이와 포함률에 같은 추출을 쓴다.
5. **평가 대상이 30개 미만인 층은 "표본 부족"으로 표시만 하고 해석하지 않는다**(수치는 싣는다).

## 4. 해석 규칙 (미리 고정)

- 층 사이 차이는 **상관이며 원인이 아니다.** 어떤 층이 B2를 더 흔든다고 해서 그 층의 특성이 원인이라는 뜻이 아니다(층 변수들은 서로 관련될 수 있다: 예 (a)와 (b)).
- **층을 여러 개(5개 차원, 16개 층, 두 자료) 보므로 우연히 CI가 0을 벗어나거나 포함률이 80%에서 벗어나는 층이 있을 수 있다.** 다중 비교 보정은 하지 않는다. CI가 0을 포함하면 "점추정은 컸으나(작았으나) 우열을 확정할 수 없음" 또는 "현재 자료로 뚜렷한 연관성을 확인하지 못함"이라고 쓴다. "나빴다", "영향 없음", "효과 없음"은 쓰지 않는다. CI **하한이 0보다 클 때만** "B2가 B0보다 오차가 큼"이라고 쓴다.
- 포함률의 CI가 80%를 포함하면 "명목 80%에서 벗어났다고 확정할 수 없음", 상한이 80%보다 작으면 "명목 80%보다 낮음", 하한이 80%보다 크면 "명목 80%보다 높음". "검증됐다", "보장한다"는 쓰지 않는다.
- test cold-start 결과는 **이미 열람한 자료의 탐색 결과**이며 train 결과와 일치하는지만 기술한다. test로 규칙을 정하지 않는다.
- **이 결과로 시연 규칙(B2 식·파라미터·범위·문구)을 바꾸지 않는다.** 바꿔야 하면 train 교차검증으로 규칙을 정하고 사양을 먼저 커밋한다.

## 5. 해석 보완 (정의에 없는 부분의 가장 좁은 읽기, 실행 전 고정)

1. **x = 0**은 `T5(기준) − m`이 부동소수점으로 정확히 0.0인 경우다(m = 기준 기록인 경우와, 과거 5km가 2개 이상인데 중앙값이 기준 기록과 정확히 같은 경우 모두; `docs/m_construction_5km.md`).
2. (a)의 "1개(x = 0)" 층은 과거 유효 5km가 기준 기록 1개뿐인 평가 대상이다(과거 5km가 2개 이상이면서 x = 0인 평가 대상은 (a) 2~4개 또는 5개 이상 층에 들어가고 (b) 0초 층에도 들어간다).
3. (e)의 정지 시간은 기준 기록 세션 전체(5.0~5.5km 세션)의 점 기록에서 계산한다. T5 구간(5.000km 지점까지)만이 아니다. 시간차가 0 이하인 구간과 속도가 1km/h 이상인 구간은 정지가 아니다.
4. (c)의 며칠은 기준 기록 세션의 **종료 시각**에서 t까지(소수 일)다.
5. 층 안 사용자 평균 MAE는 사용자별로 그 층 안 평가 대상의 절대 오차 평균을 구해 사용자 수로 평균한 것이다. 포함률은 층 안 풀링이다.
6. 분위수·CI는 `np.percentile` 기본값(선형 보간)이다.
7. 폴드 밖 ŷ_oof의 행 순서와 폴드 분할은 `55_interval_calibration_5km.py`의 `oof_quantiles`와 같다(스크립트가 같은 q10_oof·q90_oof를 재계산해 assert로 확인).
