# 보고용 정리 표 1: 기준치(B2) 대비 모델 비교와 표본 감소 연결

생성: `scripts/57_baseline_table_5km.py`. 새 학습 없이 최종 평가(49c02f8)가 저장한 예측값(`data/final_preds_5km.pkl`, git 제외)과 정답으로 **집계만** 했다. 결과 숫자·정의·모형·범위는 바꾸지 않았다. 시각은 start_time 원값(기준 미확인)이며 상관관계까지만 주장한다. 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다. ID·행 값은 싣지 않았다.

- 단위: 초. 오차 = |정답 y − 예측|. 사용자별 MAE = 그 사용자의 평가 기준 시점들의 평균 절대 오차. **차이 = 사용자별 (모델 MAE − B2 MAE)**이며 음수이면 모델 쪽이 낮다.
- **주 판정은 평균 차이의 95% CI로만 낸다.** CI가 0을 포함하면 "우열 확정 불가(동등성 입증 아님)", CI 하한이 0보다 크면 "B2보다 나쁨", 상한이 0보다 작으면 "B2보다 좋음"이다. 중앙값·비율은 보조이며 판정에 쓰지 않는다. 중앙값은 항상 "사용자별 오차 차이 중앙값 기준"으로 부른다.
- CI: 사용자 단위 cluster bootstrap(2,000회, seed 42), 사용자를 복원추출하고 모든 방법에 같은 추출(쌍대), 백분위 95% CI. 42번(`42_final_eval_5km.py`)과 같은 추출이다.
- **검증(assert)**: 모든 모델의 사용자 평균 MAE, B2 사용자 평균 MAE, 기본 입력 3개와 E-MLP 3개의 (모델 − B2) 평균·CI가 `docs/final_results_5km.md`(49c02f8)의 값과 소수 3자리까지 같다.
- "모델이 더 나은 사용자 비율" = 차이 < 0인 사용자 수 / 사용자 수(동률은 더 나은 쪽에 넣지 않고 따로 표시). 평가 대상이 1개뿐인 사용자도 사용자 1명으로 센다.
- 평균 차이의 CI와 사용자별 오차 차이 중앙값 기준 CI가 다르게 나올 수 있다(일부 행은 중앙값 쪽 CI만 0을 벗어난다). 판정은 평균 차이에 따르고, 중앙값은 극단 사용자의 영향을 줄여 보는 보조 확인이다. 행이 많아 우연히 CI가 0을 벗어나는 행이 있을 수 있다(다중 비교 보정 없음).
- 판정 요약(49c02f8 결론 범위): 현재 입력·분할·평가 조건에서 B2의 통계적·실용적 통과 기준을 만족한 모델은 없었다. 아래 보조 행의 판정은 요약에 쓰지 않는다(다중 비교).

## C. 표본 감소 연결: 초안 4,362개 → 확정 2,072개

사슬: 4,362개 →(S1 길이 하한 4.5→5.0km: −2,235)→ 2,127 →(S2 병합 세션 제외: −50)→ 2,077 →(S3 극단 기준 기록 제외: −5)→ 2,072개. 감소 2,290 = 2,235 + 50 + 5 (assert 확인).

단계별로 "과거 자격 탈락"(②→③: 직전 28일 안에 기준 기록이 될 5km 후보가 없음)과 "미래 관측 탈락"(③→④: 다음 7일 안에 5km 후보가 없음)을 나눴다. ④ 평가 대상 = ② − 과거 자격 탈락 − 미래 관측 탈락이므로, ④의 변화 = −(과거 자격 탈락의 변화) − (미래 관측 탈락의 변화)이다(assert). ②(직전 28일 달리기 4회 이상)는 모든 단계에서 38,005개로 같다. 전체(train+test) 기준 기준 시점 수이며, 출처는 `docs/sample_reduction_5km.md` 1절(`scripts/48_sample_reduction_5km.py`)이다.

| 단계 | 바꾼 정의 | 과거 자격 탈락 (②→③) | 미래 관측 탈락 (③→④) | ④ 평가 대상 | ④ 변화의 구성: 과거 자격 쪽 / 미래 관측 쪽 |
|---|---|---|---|---|---|
| S0 → S1 | 후보 길이 하한 4.5 → 5.0km | 20,841 → 26,322 (+5,481) | 12,802 → 9,556 (-3,246) | 4,362 → 2,127 (-2,235) | -5,481 / +3,246 |
| S1 → S2 | 병합 세션을 후보에서 제외 | 26,322 → 26,590 (+268) | 9,556 → 9,338 (-218) | 2,127 → 2,077 (-50) | -268 / +218 |
| S2 → S3 | 극단(T5 > 5,000초) 후보를 기준 기록에서 제외 (= 확정 정의) | 26,590 → 26,642 (+52) | 9,338 → 9,291 (-47) | 2,077 → 2,072 (-5) | -52 / +47 |

- 합계: ④ 변화 2,290개 감소 = 과거 자격 쪽 -5,801 + 미래 관측 쪽 +3,511. 단계마다 두 쪽이 반대로 움직이므로(길이 하한을 올리면 과거 자격을 채우는 기준 시점이 크게 줄고, 같은 하한으로 미래 관측 탈락도 줄어든다) 어느 한쪽 숫자만으로 감소를 설명하지 않는다.
- 표본이 줄면 CI가 넓어지므로 비유의는 동등성의 증명이 아니다. 감소의 대부분(2,235개)은 정의 변경(길이 하한: 5.0km 미만 세션에는 "세션 안의 5.000km 지점"이 없어 T5를 만들 수 없음)이다. S2·S3의 감소는 각각 50개·5개로 작다.
