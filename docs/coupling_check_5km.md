# 사후 탐색 결과: γ의 수학적 결합 점검 (5km 과제)

생성: `scripts/48_coupling_check_5km.py`. 사양: `docs/posthoc_spec_coupling_5km.md`(커밋 c7e9a33, 분석 실행 전 고정). **사후 탐색**(test 정답을 본 뒤의 분석)이며 상관관계까지만 주장한다. **어떤 결과가 나와도 γ를 훈련·회복 효과로 해석하지 않으며 인과·처방 표현을 쓰지 않는다.** 주 결론(49c02f8)·모델·정의·범위·시연 예측식은 바꾸지 않았다. 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다. ID·행 값은 싣지 않았다.

배경: y = T5(정답) − T5(기준)과 x = T5(기준) − m에 같은 T5(기준)이 **반대 부호로** 들어가므로, 정답 T5가 기준 기록과 무관해도 γ는 이 결합과 측정 오차만으로 음수가 될 수 있다.

## 1. 표본과 검산

| 항목 | 평가 대상 | 사용자 |
|---|---|---|
| 43번 대상 범위(평가 대상 2개 이상 사용자의 모든 평가 대상) | 1,973 | 250 |
| (a)에서 제외: 기준 기록을 뺀 t 이전 유효 5km 세션이 없음(m_ex 없음) | 99 | 99 (제외된 평가 대상이 1개 이상인 사용자) |
| (a) 분석 표본 | 1,874 | 250 |

검산: 43번과 같은 코드·표본으로 γ를 다시 추정한 값 -0.845 [-0.934, -0.757]가 `docs/within_person_results_5km.md`의 γ와 같음을 assert로 확인했다. 모형·bootstrap(사용자 단위 2,000회, seed 42, 백분위 95% CI)은 43번과 같다. 단위는 초(y의 단위).

## 2. (a) m_ex로 γ 재추정

| 설정 | 표본 | γ (1초당) | 95% CI | CI가 0 포함 |
|---|---|---|---|---|
| 원래 γ (43번, x = T5(기준) − m, 43번 표본) | 1,973개 / 250명 | -0.845 | [-0.934, -0.757] | 아니오 |
| 대조: 같은 모형, (a) 표본에서 원래 x | 1,874개 / 250명 | -0.836 | [-0.925, -0.747] | 아니오 |
| (a) γ_ex (x_ex = T5(기준) − m_ex) | 1,874개 / 250명 | -0.737 | [-0.828, -0.631] | 아니오 |

m_ex = 기준 기록을 뺀 t 이전 유효 5km(비병합 5.0~5.5km, T5 ≤ 5,000초)의 T5 중앙값. 다른 설명 변수는 원래 모형 그대로다.

## 3. (b) 귀무 점검: 사용자 안에서 정답 T5 섞기

사용자별로 그 사용자의 평가 대상들의 정답 T5(= y + T5(기준))를 섞어 다시 배정하고 y* = T5*(정답) − T5(기준)으로 같은 모형의 γ*를 점추정했다(1,000회, seed 42; 평가 대상이 1개뿐인 사용자는 그대로, 표본은 1,973개 / 250명). x와 다른 설명 변수는 원래 값이다.

| 항목 | 값 |
|---|---|
| 원래 γ | -0.845 |
| 귀무 γ* 중앙값 | -1.012 |
| 귀무 γ* 2.5% 분위수 | -1.093 |
| 귀무 γ* 97.5% 분위수 | -0.922 |
| γ* ≤ 원래 γ 인 비율(경험적 위치) | 1.000 (1000 / 1,000) |

## 4. 해석 (사양 4절의 규칙)

- (b) **γ의 상당 부분은 정의상 결합으로 설명될 수 있음.** 귀무 분포(사용자 안에서 정답 T5를 섞어도 남는 부분)의 2.5%~97.5% 구간이 모두 0보다 작고 중앙값이 원래 γ의 절반 이하다.
- 위치: 원래 γ는 귀무 2.5%~97.5% 구간 위에 있다(원래 γ -0.845, 귀무 중앙값 -1.012, 2.5%~97.5% [-1.093, -0.922]).
- (a) γ_ex = -0.737 [-0.828, -0.631]: CI가 0을 포함하지 않지만 **상관이며 인과가 아니다**. 같은 표본 대조 γ -0.836와의 차이는 점추정만 기술한다(m에서 기준 기록 자신이 빠져도 T5(기준)이 x와 y에 반대 부호로 들어가는 구조는 그대로다).
- **어떤 결과가 나와도** γ를 훈련·회복 효과로 해석하지 않는다. 이 결과로 주 결론·모델·정의·범위·필터·시연 예측식을 바꾸지 않는다.

한계: 이 점검은 정답 T5를 사용자 안에서 섞는 한 가지 귀무만 본다. 섞으면 사용자별 수준 외의 시점·기준 기록과의 연관(실제 평균 회귀 포함)이 모두 사라진다. m이 사용자 안에서 시간에 따라 변하고 평가 대상 수가 사용자마다 달라(1개뿐인 사용자 포함) γ*의 값은 이 표본의 구조에 의존한다. 사용자 단위 불확실성은 귀무 분포 폭(반복 간 변동)만 보여 준다.
