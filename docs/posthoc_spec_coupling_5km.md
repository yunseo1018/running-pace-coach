# 사후 탐색 사양: γ의 수학적 결합 점검 (분석 실행 전 고정)

작성: 11월 1주차(P2-2번, 교수 피드백 11/4). **이 문서를 만드는 시점에 아래 (a)·(b)의 결과(재추정 γ, 귀무 분포)는 계산하지 않았다.** 주 결론은 커밋 49c02f8(최종 평가, 평가 동결 `freeze-5km-v1`)로 이미 확정됐고 이번 분석은 그것을 바꾸지 않는다.

- 분류: **사후 탐색**(test 정답을 본 뒤의 분석). 상관관계까지만 주장하며 **어떤 결과가 나와도 γ를 훈련·회복 효과로 해석하지 않는다.** 결과를 보고 모형·정의·범위를 바꾸지 않는다.
- 배경: y = T5(정답) − T5(기준)과 x = T5(기준) − m에 같은 T5(기준)이 **반대 부호로** 들어간다. 정답 T5가 기준 기록과 무관하게 정해지더라도 이 결합만으로 γ가 음수가 될 수 있다(m이 사용자 안에서 거의 일정하면 γ ≈ −1에 가까워짐). 43번의 γ(−0.845)에서 이 부분을 가려내는 점검이다.
- 표기 규칙: "start_time 원값(기준 미확인)", "관측된 러닝 기록의 공백". 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다. ID·행 값은 출력·저장하지 않고 문서에는 집계값만 싣는다.
- 정의에 명시되지 않은 사항은 아래 "해석 보완"의 가장 좁은 읽기를 적용하고, 그 밖의 판단이 필요하면 임의로 정하지 않고 멈춰서 보고한다.

## 1. 공통 모형과 표본 (43번 같은 사람 안 분석과 같음)

- 모형: y = 사용자 고정효과 + β1·(직전 28일 총 거리/10km) + β2·(직전 28일 달리기 횟수) + β3·(가장 긴 거리 km) + β4·(마지막 달리기 후 일수) + γ·x + 오차. `43_within_person_5km.py`의 `within_ols`(사용자별 평균을 뺀 within OLS).
- 대상 범위: 43번과 같음 — 평가 대상 2,072개 중 평가 대상이 2개 이상인 사용자의 모든 평가 대상(250명·1,973개). (a)에서는 여기에서 m_ex가 없는 평가 대상을 제외한다.
- 신뢰구간: 사용자 단위 bootstrap 2,000회, seed 42, 사용자를 복원추출하고 뽑힌 사용자의 모든 평가 대상 유지(같은 사용자가 여러 번 뽑히면 각각 별개 고정효과), 백분위 95%.
- 검산: 43번의 γ(−0.845 [−0.934, −0.757], `docs/within_person_results_5km.md`)를 같은 코드로 재현해 assert로 확인한다.

## 2. (a) m_ex로 γ 재추정

- **m_ex** = 기준 기록 세션을 뺀, 기준 시점 t 이전에 끝난 유효 5km 세션(비병합 5.0~5.5km, T5 ≤ 5,000초)의 T5 중앙값. 그런 세션이 없으면(= 과거 5km가 기준 기록 1개뿐) **그 평가 대상은 제외**한다.
- x_ex = T5(기준) − m_ex로 위 모형의 x를 바꿔 γ_ex를 추정한다(다른 설명 변수는 그대로).
- 보고: 포함/제외 개수와 사람 수, γ_ex와 95% CI, 그리고 **같은 표본(m_ex가 있는 평가 대상)에서 원래 x(= T5(기준) − m)로 추정한 γ**와 그 CI(표본 변화의 영향을 분리하기 위한 대조).
- 의미: m에서 기준 기록 자신이 빠지므로 x_ex는 "기준 기록이 본인의 다른 5km 기록과 얼마나 다른가"가 된다. 여전히 T5(기준)이 x_ex와 y에 반대 부호로 들어가므로 결합이 완전히 사라지지는 않는다.

## 3. (b) 귀무 점검: 사용자 안에서 정답 T5를 섞기

- 사용자별로 그 사용자의 평가 대상들의 **정답 T5(= y + T5(기준))를 무작위로 섞어 다시 배정**하고(평가 대상이 1개뿐인 사용자는 그대로), y* = T5*(정답) − T5(기준)을 만든다. x와 다른 설명 변수는 원래 값 그대로다(원래 m 사용).
- 섞은 자료로 같은 모형의 γ*를 점추정한다(bootstrap CI는 계산하지 않음). **1,000회, seed 42**(`np.random.default_rng(42)`, 반복마다 사용자를 정렬 순서대로 섞음). 대상 표본은 1절의 43번 표본(250명·1,973개) 전체다.
- 보고: 원래 γ, 귀무 분포 γ*의 중앙값·2.5%·97.5% 분위수, 원래 γ보다 작거나 같은 γ*의 비율(경험적 위치). 이 귀무에서는 정답 T5가 사용자별 수준 외에는 기준 기록·시점과 무관하므로 γ*는 "정의상 결합"만 담는다.

## 4. (c) 해석 규칙 (미리 고정)

"크게 음수"는 사양에서 정의하지 않았으므로 **실행 전에 아래처럼 고정한다**(숫자는 이 점검에만 쓰는 조작적 정의이며 결과를 본 뒤 바꾸지 않는다):

- 귀무 분포의 2.5%~97.5% 구간이 **모두 0보다 작고**, 귀무 중앙값이 **원래 γ 점추정의 절반 이하(음수 방향으로 절반 이상)**이면 귀무 분포가 "크게 음수"다.
- 크게 음수이면 다음 문장을 쓴다: **"γ의 상당 부분은 정의상 결합으로 설명될 수 있음"**.
- 크게 음수가 아니면: "귀무 분포에서는 γ와 같은 크기의 음의 값이 나타나지 않았다(정의상 결합만으로는 γ 전부가 설명되지 않는 것으로 보임)"로 쓰되, 이것이 훈련·회복 효과의 증거라고 쓰지 않는다. 귀무가 모든 연관(예: 평균 회귀)을 없애지 않을 수 있음을 함께 쓴다.
- 원래 γ가 귀무 2.5%~97.5% 구간 안이면 "원래 γ는 귀무에서 흔히 나오는 범위", 구간 아래(더 음수)이면 "귀무보다 더 음수"라고 위치만 기술한다.
- (a)의 γ_ex는 CI가 0을 포함하면 "관계를 확인하지 못함", 포함하지 않아도 상관이며 인과가 아니라고 쓴다. 원래 γ와의 차이는 점추정만 기술한다.
- **어떤 결과가 나와도** γ를 훈련·회복 효과로 해석하지 않고, 인과·처방 표현을 쓰지 않는다.
- 이 결과로 주 결론(49c02f8), 모델, 정의, 범위, 필터, 시연 예측식(`demo/b2_params.json`)을 바꾸지 않는다. 바꿔야 하면 train 교차검증으로 규칙을 정하고 test 결과는 "탐색 결과"로 표기한다.

## 5. 해석 보완 (정의에 없는 부분의 가장 좁은 읽기, 실행 전 고정)

1. **유효 5km 세션**: 비병합이고 `actual_distance_km ∈ [5.0, 5.5]`이며 극단(T5 > 5,000초)이 아닌 5km 후보 — `m`을 만들 때 쓰는 `past` 집합과 같다(`docs/m_construction_5km.md`). 종료 시각 < t, 기준 기록 세션은 제외.
2. **정답 T5의 값**: T5(정답) = y + T5(기준)(같은 평가 대상의 값). 극단 정답(T5 > 5,000초)도 그대로 둔다(주 분석과 같음).
3. **섞는 범위**: 같은 사용자의 평가 대상(1절 표본) 사이에서만 섞는다. 사용자 사이에서는 섞지 않는다.
4. **γ*의 경험적 위치**: (γ* ≤ 원래 γ)인 반복 수 / 1,000.
5. (a)의 같은 표본 대조 γ는 (a) 표본(m_ex가 있는 평가 대상)에서 원래 x로 추정한 값이다(43번 γ와 표본이 다름).
