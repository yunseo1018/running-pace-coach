# 5km 과제 train 내부 모델 비교 (Ridge·GBM·MLP) — 참고용, test 미사용

생성: `40_models_cv_5km.py`. 정의: `docs/predeclaration_5km_final.md`(3fad402), `docs/predeclaration_5km_addendum.md`(9fb0d8f). **이 결과는 train 사용자 내부 참고용이며 공식 판정이 아니다.** 공식 판정은 test 1회 평가로 한다. test 사용자의 정답은 계산하지 않았다. 시각은 start_time 원값(기준 미확인), 상관관계까지만 주장한다.

- 대상: train 평가 대상 1,720개·278명, 같은 GroupKFold(5, seed 42), 사용자는 폴드 사이에 겹치지 않음(assert). 단위는 초.
- **선택 편향**: 하이퍼파라미터 선택과 성능 추정에 같은 폴드를 쓴다. 설정마다 5개 폴드의 폴드 밖 예측을 만들고 사용자 평균 MAE가 가장 낮은 설정을 골라 그 설정의 폴드 밖 예측을 보고하므로, 아래 점수는 낙관적으로 치우칠 수 있다.
- 모델·손실(기존 구현 그대로): Ridge = 제곱오차+L2(alpha 격자 10개), GBM = `gbt_lib` absolute_error(learning_rate{0.03,0.1}×max_iter{100,300}×max_depth{2,3}, min_samples_leaf 20, n_bins 32), MLP = torch `L1Loss`(Adam lr 1e-3, 배치 2048, 최대 200에폭, patience 15; hidden_layers{1,2}×width{32,64}×weight_decay{0,1e-4}). MLP는 학습 폴드 안 사용자 20% 내부 검증으로 에폭 수를 정하고 학습 폴드 전체로 재학습(시드 42 하나).
- 전처리(표준화)는 학습 폴드에서만 적합. 타깃은 y(초) 그대로. 선택 기준 = 폴드 밖 사용자 평균 MAE.
- CI: 사용자 단위 cluster bootstrap(278명씩 복원추출 2000회, seed 42), 뽑힌 사용자의 모든 기준 시점 유지, 모든 방법에 같은 추출(쌍대), 백분위 95% CI. 방향 밴드 ±10초.
- 환경: numpy 2.5.3, pandas 3.0.6, torch 2.14.0+cpu.

## 6. 구현상 관찰과 한계 (사전 선언한 설정을 바꾸지 않음)

- **MLP가 최대 에폭(200)에서 멈췄다**: 모든 입력 세트·모든 폴드에서 선택된 에폭 수가 상한 200이었다(1절 표). 학습 폴드가 약 1,400행이라 배치 2048에서는 에폭당 1회 갱신뿐이며, 학습 설정(배치 2048, lr 1e-3, 최대 200에폭, patience 15)은 약 8만 행의 이전 과제에 맞춰 고정된 값이다. 사전 선언("기존 격자")에 따라 설정을 바꾸지 않았으므로, MLP의 낮은 순위는 모델 구조의 한계가 아니라 이 설정에서 충분히 학습되지 않았기 때문일 수 있다(미확인). 설정을 바꾼 재실행은 탐색적 변경으로 별도 표시해야 한다.
- 입력에 T5(기준 기록)와 T5(기준 기록)−m이 모두 있어 B2의 선형 구조는 Ridge 입력 안에 포함된다. 그럼에도 Ridge가 B2를 사용자 평균 MAE에서 앞서지 못한 이유는 확인하지 않았다.
- 풀링 MAE와 사용자 평균 MAE의 결론이 갈리는 경우(예: Ridge·GBM(기본) − B2)가 있다. 집계 단위가 다르며 원인은 확인하지 않았다.
- 학습 행 수가 약 1,400개, 사용자 약 220명(폴드당)이라 모든 CI가 넓다. 한 사용자의 여러 기준 시점은 28일 입력 창이 겹쳐 독립이 아니다.
