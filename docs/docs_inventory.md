## 요약

- **스크립트가 만드는 문서**는 16개 중 3개뿐이다: `same_scope_comparison.md`(31번), `demo_performance.md`(`demo/bench_demo.py`), `sklearn_import_issue.md`(`env_tools.py`). 나머지 13개는 손으로 쓴 정의·사전 선언·감사 문서라 "다시 생성해서 대조"하는 개념이 없다(내용은 커밋 이력으로 고정).
- 이전 과제(페이스 예측·합성 코칭, README 부록)에 속한 문서는 1·3·5·6·10·11·13·14·15번(9개)이고, 5km 과제 문서는 2·4·7·8·9·16번(6개), 환경 진단은 12번 1개다.
- 재현 확인이 필요한 것은 사실상 `same_scope_comparison.md` 하나였고(31번 라벨 불일치로 재생성되지 못했던 문서), 31번 수정 후 원본 저장소에서 다시 만들어 커밋본과 같음을 확인했다(위 10번). 이로써 확인되지 않은 문서 중 스크립트가 만드는 것은 `demo_performance.md`(측정값이라 시간이 달라지는 것이 정상)와 `sklearn_import_issue.md`(시점이 들어감)뿐이다. `demo_performance.md`는 측정값이라 시간이 달라지는 것이 정상이다.
