# 사후 분석·민감도 실행 사양 (분석 실행 전 고정)

작성: 10월 5주차(학기 9주차). **같은 사람 안 분석·공백 코호트·민감도를 실행하기 전에 고정한다.** 주 결론은 커밋 49c02f8(최종 평가, 평가 동결 `freeze-5km-v1`)으로 이미 확정됐으며 이번 결과로 바꾸지 않는다.
- A·B는 **사후 분석**(test 정답을 본 뒤의 분석)이다. S1~S5는 **사전 지정 민감도**(`docs/predeclaration_5km_final.md` 18항, 커밋 3fad402)이며 하나씩 실행하되 하이퍼파라미터를 다시 고르지 않는다.
- 상관관계까지만 주장한다. 인과·처방 표현을 쓰지 않는다. 시각은 "start_time 원값(기준 미확인)", 러닝 기록의 빈 구간은 "관측된 러닝 기록의 공백"이라고 쓴다. ID·좌표·행 단위 값은 출력·저장하지 않고 중간 산출물은 `data/`에만 둔다.
- 정의에 명시되지 않은 사항은 아래 "해석 규칙"에서 **문자 그대로의 가장 좁은 읽기**를 적용하고 결과 보고에서 목록으로 제시한다. 정의에 없는 추가 제외는 하지 않는다.

## A. 같은 사람 안 분석 (사후 분석)
- 자료: 평가 대상(2,072개; `docs/dataset_counts_5km.md` 1절) 중 평가 대상이 2개 이상인 사용자(250명)의 모든 평가 대상(train·test 모두).
- 식: y = 사용자 고정효과 + β1·(직전 28일 총 거리/10km) + β2·(직전 28일 달리기 횟수) + β3·(가장 긴 거리 km) + β4·(마지막 달리기 후 일수) + γ·(T5(기준 기록) − m) + 오차.
- 추정: 사용자별 평균을 뺀 within 추정(OLS). 사용자 단위 bootstrap 2,000회(seed 42, 사용자를 복원추출하고 그 사용자의 모든 기준 시점 유지), 백분위 95% CI.
- 보고: β1~β4, γ의 점추정과 CI(단위: 초), 사용자 평균을 뺀 변수들 간 상관행렬, 표본 수(기준 시점·사용자).
- 해석 문장 형식: "같은 사람 안에서 ○○이 1단위 큰 기준 시점은 다음 5km 기록 변화가 평균 β초 달랐다(상관, 인과 아님)."

## B. 공백 코호트 (관측된 러닝 기록의 공백, 사후 분석)
- 쌍: 3fad402 19항 정의(시작 시각순으로 이웃한 두 달리기 세션이 모두 5km 후보). 겹침(공백 음수) 쌍은 제외하고 개수 보고.
- Δ = T5(둘째) − T5(첫째), 초. 음수 = 개선.
- m_first = 첫째 종료 이전에 종료된 그 사용자의 비극단 5km 후보 T5 중앙값. 이전 후보가 없으면 m_first = T5(첫째).
- 기술 통계: 공백 구간([0,7) / [7,14) / [14,28) / [28,56) / 56일 이상)별 쌍 수, 사용자 수, Δ 중앙값과 사용자 단위 bootstrap 95% CI, ±10초 기준 개선/변화 없음/악화 비율.
- 같은 사람 안 비교: Δ = 사용자 고정효과 + 공백 구간 더미(기준 = [0,7)) + γ·(T5(첫째) − m_first) + 오차. within OLS, 같은 bootstrap.
- 쌍이 30개 미만인 구간은 "참고(표본 부족)"로 표시.

## C. 민감도 S1~S5 (사전 지정 민감도, 3fad402 18항)
- 하이퍼파라미터는 84670d6에서 선택된 값 고정(다시 선택하지 않음). E-MLP는 제외(탐색적).
- 각 민감도마다 해당 정의로 데이터셋을 다시 만들고, B2의 a·b와 전처리는 그 정의의 train(또는 personalized 학습분)에서만 다시 적합.
- 평가: cold-start test와 personalized, 주 결론 표(기본 Ridge·GBM·MLP − B2)와 B2 사용자 평균 MAE, 평가 대상 수.
- S1: 5km 후보 = 비병합 4.5~5.5km, 타깃 시간 = 경과 시간 ÷ 거리 × 5 ("5km 환산 시간").
- S2: 주 분석 데이터에서 정답 세션이 극단(T5 > 5,000초)인 기준 시점을 제외(재학습 없이 49c02f8 예측값에 필터만).
- S3: 기준 시점을 −12h, −6h, +6h, +12h 이동(4개 각각).
- S4: 정답을 다음 7일 5km 후보 T5의 중앙값(S4a), 최솟값(S4b)으로 바꾼 보조 과제.
- S5: 병합 세션도 5km 후보에 포함(T5는 같은 보간 규칙, 조각 사이 공백 포함).
- 통과 판정(참고 표기): 모델 − B2의 사용자 평균 MAE 차이 95% CI 상한 < 0을 "통계적으로 넘음"으로 센다. 주 결론(49c02f8)은 바뀌지 않는다.

## 해석 규칙 (정의가 문자 그대로 정하지 않은 부분)
1. **분석 자료의 T5**: 49c02f8에서 test 사용자 T5와 y를 처음 계산했다. 이번 분석은 그 값을 재사용하지 않고 같은 코드(`38_build_5km_dataset.py`의 T5 계산·`42_final_eval_5km.py`의 데이터셋 구성)로 다시 만들며, 주 분석 데이터셋이 49c02f8의 평가 행(cold test 352개, personalized 442개)과 일치하는지 assert로 확인한다.
2. **A의 변수**: 총 거리/10km = 직전 28일 창 안 세션 거리 합 ÷ 10; 달리기 횟수 = 창 안 세션 수(병합 세션 1회); 가장 긴 거리 = 창 안 최대 `actual_distance_km`; 마지막 달리기 후 일수 = 창 안 가장 늦은 종료 시각부터 t까지(일, 소수); T5(기준 기록) − m은 데이터셋의 `t5_ref_minus_m`. 상수항은 within 변환에서 사라진다.
3. **A의 bootstrap**: 사용자를 복원추출하며, 같은 사용자가 여러 번 뽑히면 각각 별개 고정효과로 취급한다(사용자별 충분통계를 더해 추정).
4. **B의 극단 T5**: 쌍의 첫째·둘째 세션이 극단(T5 > 5,000초)이어도 쌍에서 제외하지 않는다(정의에 제외 규칙이 없음). 극단이 관여한 쌍의 수를 함께 보고한다. m_first에는 비극단 후보만 쓴다.
5. **B의 m_first**: "첫째 종료 이전에 종료된" = 종료 시각이 첫째의 종료 시각보다 엄밀히 이른 비병합·비극단 5km 후보(첫째 자신 제외). 없으면 m_first = T5(첫째).
6. **B의 Δ 중앙값 CI**: 사용자를 복원추출한 뒤 뽑힌 사용자의 해당 구간 쌍 전체의 Δ 중앙값을 반복 계산한 백분위 구간. 해당 구간에 쌍이 하나도 안 뽑힌 추출은 제외하고 그 비율을 적는다.
7. **S1**: 극단 기준은 환산 T5 > 5,000초로 동일. 기준 기록·정답·m은 환산 T5로 같은 규칙을 적용. 거리 범위만 4.5~5.5km로 넓어지고 병합 세션은 후보에서 제외.
8. **S2**: 49c02f8의 저장된 예측값에서 정답 세션이 극단인 평가 행만 제거하고 지표·CI를 다시 계산(사용자 단위 bootstrap 같은 방식). 재학습 없음.
9. **S3**: 이동은 start_time 원값 기준으로 격자를 옮긴다(t' = t + 이동, 같은 주 번호). 후보 정의·T5·분할 파일은 주 분석과 같다.
10. **S4**: 정답 = 다음 7일 5km 후보(극단 포함)의 T5 중앙값 또는 최솟값 − T5(기준 기록). 기준 기록·m·입력은 주 분석과 같다.
11. **S5**: 5km 후보 = `actual_distance_km ∈ [5.0, 5.5]`인 세션(병합 세션 포함). 병합 세션의 T5는 구성 조각을 시작 시각순으로 이어 조각 거리 합이 5.000km에 처음 도달하는 조각 안에서 선형 보간하고, (그 시각 − 첫 조각의 첫 timestamp)를 쓴다(조각 사이 공백이 경과 시간에 포함).
12. **모델·MLP 에폭**: 84670d6에서 선택된 기본(11) 입력의 Ridge·GBM·MLP 설정을 그대로 쓰고, MLP 에폭 수는 49c02f8과 같이 학습 자료 안 사용자 20% 내부 검증(seed 42)으로 정한다. personalized 학습·평가 분할 규칙은 `predeclaration_5km_final.md` 15항 그대로(민감도 데이터셋마다 다시 적용).
13. **분할 사용자**: cold-start는 기존 분할 파일(train 598명, test 150명)을 그대로 쓴다. 민감도에서 평가 대상이 없는 사용자는 자연히 빠진다.
