# 5km 과제 사전 선언 확정본

확정: 10월 5주차(학기 9주차, 사용자 지시에 따른 결정). 이 문서는 `docs/week4_predeclaration_5km.md`(초안)의 `[결정 필요]` 항목을 모두 확정한 것이다.
**이 문서 작성 시점까지 정답 y(5km 기록 변화)와 5km 시간 T5를 어떤 자료에서도 계산하지 않았다.** 확정 이후 정의·지표·판정 기준을 결과를 본 뒤 바꾸지 않는다. 바꾸면 "탐색적 변경"으로 표시하고 원래 선언과 함께 보고한다.
표기 규칙: 시각은 "start_time 원값(기준 미확인)"이며, 러닝 기록의 빈 구간은 "관측된 러닝 기록의 공백"이라고 쓴다. 상관관계까지만 주장하고 인과·처방 표현은 쓰지 않는다.

1. **연구 질문**: 지난 4주 동안 몇 번, 얼마나 멀리, 얼마나 쉬면서 달렸는지로 다음 7일 안 첫 5km 기록의 변화를 예측하고, 같은 사람 안에서 어떤 달리기 패턴 뒤에 기록이 좋아졌는지 본다(상관관계까지만).
2. **세션 집합**: 정리된 세션 표(105,709건, `data/run_sessions_deduped_merged.pkl`). 시각은 start_time 원값(기준 미확인).
3. **기준 시점 t**: 각 사용자의 첫 세션 시작~마지막 세션 시작 사이의 모든 월요일 00:00(start_time 원값 기준).
4. **5km 후보 세션**: `merged_count == 1` 이고 `actual_distance_km ∈ [5.0, 5.5]`(양 끝 포함). 병합 세션은 5km 후보에서 제외하되, 달리기 횟수와 입력값 계산에는 포함한다.
5. **5km 시간 T5**: 후보 세션의 점 단위 기록에서 `01_parse_run_sessions.py`와 같은 규칙으로 누적 거리를 만들고(시간차 0 이하·속도 초과 구간은 0 누적), 5.000km에 처음 도달하는 시각을 인접 두 점 사이 선형 보간으로 구한 뒤 (그 시각 − 세션 첫 timestamp)를 초로 쓴다. 정지 시간 포함(경과 시간 기준).
6. **극단 후보**: T5 > 5,000초(1km당 1,000초 초과).
7. **과거 자격**: 종료 시각 ∈ [t−28일, t)인 달리기 세션 4회 이상(병합 세션 포함, 길이 무관), 그리고 같은 창 안에 극단이 아닌 5km 후보 1개 이상. **기준 기록** = 그 창 안 극단이 아닌 5km 후보 중 시작 시각이 가장 늦은 것.
8. **미래 관측**: 시작 시각 ∈ [t, t+7일)인 5km 후보 1개 이상(극단 포함). **정답 세션** = 그중 시작 시각이 가장 이른 것.
9. **정답 y** = T5(정답 세션) − T5(기준 기록), 초. 음수 = 개선.
10. **개인 과거 중앙값 m**: 종료 시각 < t인 그 사용자의 극단이 아닌 5km 후보 전체(28일 제한 없음)의 T5 중앙값. 1개뿐이면 m = T5(기준 기록).
11. **기준치**
    - B0: ŷ = 0
    - B1: ŷ = m − T5(기준 기록)
    - B2: ŷ = a + b × (T5(기준 기록) − m). a, b는 학습 자료에서 절대오차 합 최소(LAD)로 추정, scipy로 구현.
12. **방향 판정 밴드 ±10초**(근거: 5km 통과 구간 점 간격 90% 분위 8초, `docs/week5_target_check.md` A-3). y ≤ −10 개선, −10 < y < 10 변화 없음, y ≥ 10 악화. ŷ도 같은 규칙으로 분류.
13. **지표**: 주 지표 = 사용자별 MAE의 동일 가중 평균(사용자 평균 MAE). 보조 = 풀링 MAE, 방향 일치율(풀링·사용자 평균). 모든 차이는 같은 기준 시점 쌍대 비교, 사용자 단위 bootstrap 2,000회(seed 42), 백분위 95% CI.
14. **통과 기준**(모델 vs 최고 기준치, 사용자 평균 MAE 기준): 통계적 통과 = 차이(모델 − 기준치)의 95% CI 상한 < 0. 실용적 통과 = 점추정 개선 ≥ 10초. 둘을 따로 보고한다.
15. **분할**
    - cold-start = 기존 분할 파일(train 598명, test 150명). test는 모델과 기준치를 함께 **1회만** 평가한다.
    - 개발 단계 평가 = train 사용자 GroupKFold(5, seed 42).
    - personalized = 사용자별 평가 대상 기준 시점을 시간순 정렬, 평가 = 뒤쪽 max(1, round(0.2n))개(n ≥ 2), 학습 = t + 7일 ≤ 첫 평가 기준 시점인 것만. n = 1 사용자는 제외. cold-start와 결과를 따로 보고한다.
16. **입력(기본 모형)**: 직전 28일 달리기 횟수, 총 거리, 주별 거리 4개, 가장 긴 거리, 마지막 달리기 종료 후 t까지 일수, 평균 심박, T5(기준 기록), T5(기준 기록) − m. 사전 지정 추가 비교: 기본 + 평균 페이스(직전 28일 세션 페이스 평균), 기본 + 성별. T5(기준 기록) 관련 입력의 중요도는 훈련 효과로 해석하지 않는다.
17. **모델**: Ridge(`ridge_lib`), GBM(`gbt_lib`), MLP(torch). 탐색 범위는 기존 격자 재사용. 선택 기준 = train GroupKFold 사용자 평균 MAE. 스케일링·대체값 등 전처리는 학습 폴드에서만 적합.
18. **민감도(사전 지정)**: S1 5km 환산 시간(4.5~5.5km 비병합, 경과 시간÷거리×5) / S2 정답 극단 제외(사후 민감도로만) / S3 기준 시점 ±6h, ±12h 이동 / S4 다음 7일 중앙값·최솟값 타깃(보조 과제) / S5 병합 세션 포함.
19. **보조 코호트(관측된 러닝 기록의 공백)**: 시작 시각순으로 이웃한 두 달리기 세션이 모두 5km 후보인 쌍. 공백 = 둘째 시작 − 첫째 종료(일). 구간 [0,7) / [7,14) / [14,28) / [28,56) / 56일 이상. 주 분석과 별개 코호트로 보고한다.
20. **최종 확인 자료**: 기존 test를 그대로 쓰고, 이전 과제에서 결과를 본 사실은 `docs/results_viewed_log.md`에 기록한다.
