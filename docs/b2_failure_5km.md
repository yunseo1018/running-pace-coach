## 6. 읽는 법 (사양 4절의 해석 규칙)

- 층 사이 차이는 **상관이며 원인이 아니다.** 층 변수들은 서로 관련될 수 있다(예: (a)와 (b)는 과거 5km가 1개뿐이면 x = 0).
- 층을 여러 개(5개 차원, 16개 층, 두 자료) 보므로 **우연히 CI가 0을 벗어나거나 포함률이 80%에서 벗어나는 층이 있을 수 있다.** 다중 비교 보정은 하지 않았다. CI가 0을 포함하면 "점추정은 컸으나(작았으나) 우열을 확정할 수 없음" 또는 "현재 자료로 뚜렷한 연관성을 확인하지 못함"이다. CI 하한이 0보다 클 때만 "B2가 B0보다 오차가 큼"이라고 쓴다.
- 포함률의 CI가 80%를 포함하면 "명목 80%에서 벗어났다고 확정할 수 없음"이다. 표본 부족 층은 해석하지 않는다.
- test cold-start는 이미 열람한 자료의 탐색 결과이며 train 결과와 방향이 같은지만 본다.
