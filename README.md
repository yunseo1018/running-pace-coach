# 러닝 페이스 예측 및 목표 기반 코칭 에이전트

러닝 기록 시계열을 바탕으로 다음 러닝 세션의 페이스를 예측하고, 사용자가 설정한 목표(거리·목표 페이스·데드라인)에 맞춰 훈련 스케줄과 코칭 문구를 생성하는 프로젝트입니다.

서강대학교 가상융합전문대학원 「AX 이론과 활용」 수업 프로젝트로 진행 중입니다.

## 배경

기존 러닝 앱들은 단순 기록만 보여줄 뿐, "다음에 어떻게 훈련해야 하는지"에 대한 근거 있는 가이드를 주지 않습니다. 이 프로젝트는 과거 러닝 기록을 학습해 다음 세션의 페이스를 예측하고, 사용자의 목표 대비 진행 상황을 계산해 근거 있는 코칭을 제공하는 것을 목표로 합니다.

## 핵심 구조

1. **페이스 예측**: 과거 N개 러닝 세션(거리·페이스·심박·날씨)을 입력으로, 다음 세션의 평균 페이스를 예측
2. **목표 격차 계산**: 사용자가 설정한 목표(거리·목표 페이스·데드라인)와 예측값을 비교해 진행 상황 계산
3. **코칭 생성**: 예측 결과와 목표 격차를 바탕으로 훈련 조언 문구 생성

비교 모델: 최근 N회 평균 / 선형회귀·MLP / LSTM / Transformer

## 사용 데이터

- **학습용**: [FitRec/Endomondo 데이터셋](https://cseweb.ucsd.edu/~jmcauley/datasets/fitrec.html) (UCSD McAuley Lab)
  - Ni, Muhlstein, McAuley, "Modeling heart rate and activity data for personalized fitness recommendation" (WWW, 2019)
  - **라이선스 정책(academic use only, 재배포 금지)에 따라 데이터 파일은 이 저장소에 포함하지 않았습니다.** 위 링크에서 직접 다운로드해 `data/` 폴더에 넣어주세요.
- **개인화 데모용**: 나이키 런 클럽 → 애플 헬스/구글 핏 동기화를 통한 개인 러닝 기록 (GPX/TCX)
