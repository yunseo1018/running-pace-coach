# m 구성 확인 (P2-1, 읽기 전용 점검)

생성: `scripts/51_m_construction_5km.py`. 평가 대상(2,072개)의 m을 만드는 코드(`42_final_eval_5km.py`, `38_build_5km_dataset.py`)를 읽고, 같은 논리로 m에 쓰인 세션을 모아 확인했다. 개수만 싣고 ID·T5 값은 싣지 않았다. 결과 숫자·정의는 바꾸지 않았다.

## 1. m 계산 코드 (인용)

`42_final_eval_5km.py` (최종 평가 데이터셋을 만드는 함수 `build_dataset`):

```text
76:             inwin = (e >= t - m38.WIN) & (e < t)
...
84:             ref = int(valid[-1])
85:             fut = np.flatnonzero(iscand & (s >= t) & (s < t + WEEK))
86:             if len(fut) == 0:
87:                 continue
88:             ans = int(fut[0])
89:             past = np.flatnonzero(iscand & (e < t) & ~ext)
90:             m = float(np.median(t5[past]))
91:             if len(past) == 1:
92:                 m = float(t5[ref])
```

`38_build_5km_dataset.py` (train 데이터셋, 같은 논리):

```text
127:             past = np.flatnonzero(iscand & (e < t) & ~ext)
...
144:                 m = float(np.median(t5[past]))
145:                 if len(past) == 1:
146:                     m = float(t5[ref])
```

- `past`(m 계산에 쓰는 과거 5km 후보)는 `iscand & (e < t) & ~ext`: 5km 후보이면서 **종료 시각이 t보다 이르고** 극단이 아닌 세션이다(사전 선언 문서의 정의: 종료 시각 < t인 비병합·비극단 5km 후보 전체, 기준 기록 포함).
- **기준 기록 세션은 m에 들어간다.** 기준 기록은 입력 창 `[t−28일, t)`에 끝난 세션이라 `e < t`를 만족하고 극단이 아니기 때문이다(`ref = valid[-1]`, 84행). 그래서 x = T5(기준) − m은 기준 기록 자신을 포함한 중앙값에서 뺀 값이다(아래 `x = 0`이 생기는 이유).
- **정답 세션이 들어갈 여지는 없다.** 정답 세션은 `s >= t`(85행)로 시작 시각이 t 이후이므로 종료 시각도 t 이후이고, `e < t` 조건에서 걸러진다. t 이후에 끝난 세션도 마찬가지다.
- 위 두 가지(정답 세션·t 이후 종료 세션이 `past`에 없음)를 평가 대상 2,072개 모두에서 assert로 확인했다.
- 과거 5km가 1개뿐이면(`len(past) == 1`) `m = T5(기준 기록)`으로 둔다(91~92행; 사전 선언 확정 사항). 이 경우 x = 0이다.

## 2. 확인 결과 (개수)

| 집단 | 평가 대상 | 기준 기록이 m 계산에 들어감 | 정답 세션이 들어감 | t 이후에 끝난 세션이 들어감 | 과거 5km가 기준 기록 1개뿐(m = 기준 기록) | x = 0 (정확히 같음) | └ 과거 5km가 2개 이상인데도 x = 0 |
|---|---|---|---|---|---|---|---|
| 전체 | 2,072 | 2,072 | 0 | 0 | 131 | 247 | 116 |
| train | 1,720 | 1,720 | 0 | 0 | 109 | 201 | 92 |
| test | 352 | 352 | 0 | 0 | 22 | 46 | 24 |

`past` 크기: 중앙값 10, 25%·75% 분위수 4·20, 1개뿐인 평가 대상 131개. "과거 5km가 기준 기록 1개뿐"은 `docs/dataset_counts_5km.md` 2절의 "④ 중 m = 기준 기록"(전체 131, train 109, test 22)과 같다. x = 0은 이 경우와, 과거 5km가 2개 이상이지만 중앙값이 우연히 기준 기록과 정확히 같은 경우(중앙값이 가운데 값 하나일 때)를 합한 수다.

해석: 이 평가 대상들은 x = 0이므로 γ·x 항이 y에 기여하지 못한다(평균 회귀 규칙 B2의 보정 항이 0이 되어 예측 = a). 수학적 결합 점검은 `docs/coupling_check_5km.md`(사양 `docs/posthoc_spec_coupling_5km.md`)에서 다룬다.
