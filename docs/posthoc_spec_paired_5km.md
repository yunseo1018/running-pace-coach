# 사후 탐색 사양: 사용자별 짝지은 오차 차이 (분석 실행 전 고정)

작성: 11월 1주차(P1-5번). **이 문서를 만드는 시점에 이 분석의 결과(사용자별 차이의 분포·비율)는 계산하지 않았다.** 주 결론은 커밋 49c02f8(최종 평가, 평가 동결 `freeze-5km-v1`)로 이미 확정됐고 이번 분석은 그것을 바꾸지 않는다.

- 분류: **사후 탐색**(test 정답을 본 뒤의 분석). 상관관계까지만 주장한다. 결과를 보고 모형·정의·범위를 바꾸지 않는다.
- 새로 학습하지 않는다. 49c02f8이 저장한 평가 행별 예측값(`data/final_preds_5km.pkl`, git 제외)만 읽는다. ID·행 단위 값은 출력·저장하지 않고 문서에는 집계값만 싣는다.
- 표기 규칙: "start_time 원값(기준 미확인)", "관측된 러닝 기록의 공백". 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다.

## 1. 정의

- 대상: 49c02f8의 두 평가 조건 — cold-start test(352개·71명)와 personalized(442개·250명). 각각 따로 계산한다.
- 모델: 기본 입력(11) Ridge·GBM·MLP(주 결론의 3개 비교와 같은 모델), 기준치 B2.
- 사용자 u의 평가 대상 집합에서 **d_u = (모델의 사용자 u MAE) − (B2의 사용자 u MAE)** (초). 같은 평가 대상에 대한 쌍대 차이이며 음수 = 모델 쪽이 오차가 작음.
- 평가 대상이 1개뿐인 사용자도 포함한다(주 지표의 사용자 평균 MAE와 같은 정의).

## 2. 보고 항목 (이 순서)

1. 사용자 수와 사용자당 평가 대상 수의 분포(중앙값, 25%·75% 분위수, 1개뿐인 사용자 수).
2. 각 모델 − B2에 대해: d_u의 평균(= 49c02f8의 "사용자 평균 MAE 차이", `docs/final_results_5km.md`와 같은 값이어야 하며 assert로 확인), 중앙값, 25%·75% 분위수, 5%·95% 분위수.
3. d_u < 0(모델이 낮음) · d_u = 0 · d_u > 0(모델이 높음)인 사용자 수와 비율. d_u = 0은 정확히 0인 경우만 센다.
4. 사용자 단위 bootstrap 95% CI: d_u의 중앙값, d_u > 0인 사용자 비율. 사용자를 복원추출하고(2,000회, seed 42, 백분위 CI) 같은 추출을 모든 모델·조건에 쓴다.

## 3. 해석 규칙 (미리 고정)

- d_u 평균의 CI는 49c02f8과 같은 값이다(이 문서에서 새로 계산하지 않고 인용만 한다).
- 중앙값의 CI가 0을 포함하면 "점추정은 컸으나(또는 작았으나) 우열을 확정할 수 없음" 또는 "현재 자료로 뚜렷한 연관성을 확인하지 못함"이라고 쓴다. "나빴다", "영향 없음", "효과 없음"은 쓰지 않는다. 비유의는 동등성의 증명이 아니다.
- CI **하한이 0보다 클 때만** "B2보다 나쁨"이라고 쓴다.
- d_u > 0 비율의 CI가 0.5를 포함하면 "절반 이상의 사용자에서 모델이 높다고(또는 낮다고) 확정할 수 없음"으로 쓴다. 이 분석은 사용자 수가 적은 조건(cold-start 71명)에서 불확실성이 크다는 점을 함께 쓴다.
- 이 분석의 결과로 주 결론, 모델, 정의, 범위, 필터, 시연 예측식(`demo/b2_params.json`)을 바꾸지 않는다. 바꿔야 하면 train 교차검증으로 규칙을 정하고 test 결과는 "탐색 결과"로 표기한다.
- 사용자별 오차는 평가 대상 수가 적은 사용자에서 매우 변동이 크다(1개뿐인 사용자의 MAE는 그 한 건의 오차). 이를 "사용자 능력의 차이"로 해석하지 않는다.

## 4. 해석 보완 (정의에 없는 부분의 가장 좁은 읽기, 실행 전 고정)

1. 평가 대상 순서·분할은 `data/final_preds_5km.pkl`에 저장된 그대로 쓴다. B2 예측은 그 파일의 값(조건별로 그 조건의 학습 자료에서 적합한 a·b)이다.
2. 예측값이 저장된 모델 이름은 49c02f8과 같은 키(`("Ridge", "기본(11)")`, `("GBM", "기본(11)")`, `("MLP", "기본(11)")`, `"B2"`)를 쓴다.
3. 비율은 사용자 수를 분모로 한다(평가 대상 수가 아님).
