# 데모 명목 80% 범위 점검 (cold-start test · personalized, 탐색 결과)

생성: `demo/make_b2_params.py`. 시연의 범위 규칙은 **train 사용자 단위 GroupKFold(5, seed 42) 폴드 밖 잔차의 10%·90% 분위수**다(사양 `docs/interval_calibration_spec_5km.md`, 결과·CI는 `docs/interval_calibration_5km.md`). test는 이미 열람한 자료이므로 아래 포함률은 **탐색 결과**이며 "검증됐다"고 쓰지 않는다. 명목 80%는 개인에게 80%를 보장한다는 뜻이 아니다. 주 결론(49c02f8)·모델·정의·분할은 바꾸지 않았다.

- B2: a = -15.287초, b = -0.7912 (cold-start 학습 자료 1,720개에서 LAD). 정답 y = 다음 5km 기록 − 기준 기록(초).
- 시연 범위 = ŷ + [-202.1, 277.9]초 (폴드 밖 잔차 분위수). 기존 범위(참고) = ŷ + [-199.8, 276.5]초 (train 전체 적합의 표본 내 잔차 분위수; `demo/b2_params.json`의 `resid_q10_insample`·`resid_q90_insample`).
- cold-start 평가의 B2 예측은 49c02f8 저장 예측과 일치함을 assert로 확인했다. personalized 평가도 같은 파라미터(cold-start 학습 자료 기준)를 그대로 쓴다.
- 주의: personalized 평가 행에는 학습 자료(train 사용자)에 속한 사용자의 뒤쪽 기준 시점이 포함되어 학습 사용자 분포와 완전히 독립이 아니다.

| 범위 | 평가 | 평가 대상 | 사용자 | 실제 포함률 | 범위 아래로 벗어남 | 위로 벗어남 | 범위 폭(초) |
|---|---|---|---|---|---|---|---|
| 보정(폴드 밖 잔차, 시연에 사용) | cold-start test | 352 | 71 | 75.3% | 11.4% | 13.4% | 480.0 |
| 보정(폴드 밖 잔차, 시연에 사용) | personalized 평가 | 442 | 250 | 77.8% | 10.9% | 11.3% | 480.0 |
| 기존(표본 내 잔차) | cold-start test | 352 | 71 | 73.9% | 12.8% | 13.4% | 476.2 |
| 기존(표본 내 잔차) | personalized 평가 | 442 | 250 | 77.8% | 10.9% | 11.3% | 476.2 |

해석(상관·예측 정확도 점검): 포함률이 명목 80%에서 벗어난 정도만 기술한다. 포함률이 80%에 가깝다고 개별 예측이 정확하다는 뜻은 아니며(폭이 크다), 80%보다 낮거나 높으면 학습 자료와 평가 자료의 분포 차이를 시사할 뿐 원인은 미확인이다. 사용자 단위 신뢰구간은 `docs/interval_calibration_5km.md`에 있다.
