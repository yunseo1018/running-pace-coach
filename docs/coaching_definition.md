# 코칭 판정 정의 (10월 3주차 4번-1)

> **모든 목표는 합성 시나리오다. 이 데이터에는 사용자가 입력한 실제 목표(목표 거리·목표 페이스·데드라인)가 없다.** 아래 판정과 불일치율은 **고정 규칙에 대한 판정 일치도**이며, **코칭 효과나 목표 달성의 검증이 아니다.** 또한 **경과 시간 기준 페이스가 느린 세션을 체력 저하나 목표 실패로 해석하지 않는다**(신호 대기·휴식·훈련 목적·워치를 켜둔 채 쉰 시간이 포함될 수 있음).

코드 줄 번호는 이 문서 작성 시점 기준이다(`coaching_lib.py` = 코칭 모듈, `29_coaching.py` = 평가 스크립트).

## 1. 입력 (모두 사전 고정, 결과를 보고 바꾸지 않음)
| 항목 | 정의 | 코드 |
|---|---|---|
| 현재 능력 | 윈도우의 **median-5**(과거 5세션 페이스의 중앙값, 타깃 이전 기록만 사용). 실제·예측 판정 모두에 같은 값을 기준으로 쓴다. | `29_coaching.py:90`(`"cur": preds["median5"]`), median-5 계산 `25_tree_models.py:93-95` |
| 합성 목표 비율 δ | 3%, 5%, 10% | `29_coaching.py:37`(`DELTAS`) |
| 목표 페이스 | 현재 능력 × (1 − δ) | `coaching_lib.py:53-55` |
| 데드라인 | 8주(민감도 4주) | `29_coaching.py:38`(`DEADLINES`) |
| 목표 거리 | 문구 표시용(과거 5세션 평균 거리). **판정에는 쓰지 않는다.** | `29_coaching.py:89`(`dist`, 표시 전용), `coaching_lib.py:90` `make_message` |

## 2. 주차와 주간 체크포인트
- **주차** = ceil((타깃 시작 시각 − 마지막 입력 세션 종료 시각) / 7일), 최소 1 (`coaching_lib.py:47-50`; 호출 `29_coaching.py:87`). **주차 > 데드라인 주수인 윈도우는 평가에서 제외**한다(분모 정의 참고).
- **체크포인트(주 w)** = 현재 능력 + (목표 페이스 − 현재 능력) × (w / 데드라인 주수), 즉 현재 능력에서 목표 페이스까지 주 단위 선형 보간 (`coaching_lib.py:58-61`). 벡터화 버전은 `cp = cur * (1 − δ * weeks / D)` (`29_coaching.py:95-97`)이며 `coaching_lib`와 같은 결과임을 300개 표본 × 조건으로 assert 검증한다(`29_coaching.py` `벡터화 규칙 == coaching_lib 규칙 검증`).
- **격차** = 페이스 − 해당 주차 체크포인트 (초/km, 양수 = 뒤처짐) (`coaching_lib.py:64-66`).

## 3. 판정 범주 4개와 경계 (설계값, 튜닝하지 않음)
판정은 격차를 **현재 능력(현재 페이스)으로 나눈 비율** r로 한다 (`coaching_lib.py:17-19, 69-77`; 벡터화 `29_coaching.py:95-100`).

| 범주 | 조건 |
|---|---|
| 앞서감 | r ≤ −3% |
| 계획대로 | −3% < r ≤ +3% |
| 조금 뒤처짐 | +3% < r ≤ +10% |
| 크게 뒤처짐 | r > +10% |

범주 순서(인덱스 0~3)는 위 순서이며 `coaching_lib.py:21`의 `CATEGORIES`와 같다. 어떤 페이스 p의 범주는 p에 대해 단조(p가 클수록 같거나 더 뒤처진 범주)이다.

## 4. 판정 두 가지와 불일치 정의
- **실제 판정**: 실제 6번째 세션의 평균 페이스 y로 판정한 범주 (`29_coaching.py:250`, `category_idx(d["y"], …)`).
- **예측 판정**: 예측기의 예측 페이스로 판정한 범주 (`29_coaching.py:268`, `category_idx(d["preds"][p], …)`). 둘은 같은 현재 능력·같은 체크포인트·같은 주차를 쓴다.
- **불일치** = **"예측 페이스로 판정한 범주 ≠ 실제 6번째 세션 페이스로 판정한 범주"** (`29_coaching.py:269`, `inds[p] = (cat != ref)`). 두 판정이 같은 체크포인트를 쓰므로 불일치는 오직 (예측 − 실제) 페이스 차이가 범주 경계를 넘나드는지에 의해 결정된다.
- **불일치율** = 분모 윈도우 중 불일치 윈도우의 비율. 신뢰구간은 사용자 단위 cluster bootstrap(2000회, seed 42) (`29_coaching.py:108-115`).

## 5. 분모
**분모는 데드라인 이내(주차 ≤ D) 윈도우 수**이다 (`29_coaching.py:248` `keep = d["weeks"] <= D`, `:250-251`). 체크포인트나 사용자가 분모인 지표는 없다(사용자 수는 별도 표기). 데드라인 초과 윈도우의 제외 비율은 `docs/coaching_results.md` 2절(8주: cold-start 0.9%, personalized 1.5%; 4주: 2.1%, 3.3%).

## 6. 상수 규칙(다수 범주 기준선)
항상 같은 범주 하나만 말하는 규칙. 그 범주는 **평가 데이터가 아니라 학습/이력 구간**(cold-start: train 사용자 윈도우, personalized: history 윈도우)의 실제 판정 범주 최빈값으로 정하고 평가 구간에 적용한다 (`29_coaching.py:170-178`, `:257-260`).

## 7. 알려진 구조적 성질
- 현재 능력을 median-5로 정의했으므로 median-5 예측기의 예측 판정은 격차가 체크포인트 이동폭(최대 δ)뿐이라 거의 항상 '계획대로'다(`docs/coaching_results.md` 3-5절). 따라서 median-5 대비 비교는 이 시나리오의 구조 효과를 포함한다.
- 주당 체크포인트 이동폭(δ5%·8주 약 2초/km)은 예측 MAE(약 55~60초/km)보다 훨씬 작아 판정은 예측 오차와 러닝 간 변동에 지배된다(`docs/coaching_results.md` 5절).
- 불일치율이 낮다는 것은 '고정 규칙과 같은 판정을 했다'는 뜻이며 코칭이 도움이 된다는 뜻이 아니다.
