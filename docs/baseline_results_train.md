# 5km 기준치 B0~B2 — train 사용자 내부 결과 (test 미사용)

생성: `39_baselines.py` (입력 `data/5km_dataset_train.pkl`, 구축 `38_build_5km_dataset.py`). 정의는 `docs/predeclaration_5km_final.md`(커밋 3fad402).
**test 사용자의 정답 y와 T5는 계산하지 않았다.** 아래 결과는 train 사용자 평가 대상(개발 단계 평가)이며 최종 평가가 아니다. 시각은 start_time 원값(기준 미확인).

- 평가 단위: 기준 시점 1,720개, 사용자 278명(train 사용자 중 평가 대상이 있는 사용자). 단위는 초(T5, y, MAE).
- 분할: train 사용자 GroupKFold(5, seed 42, `ridge_lib.group_kfold_indices`), 폴드별로 사용자가 겹치지 않음을 assert로 확인. B0·B1은 학습이 없고 B2의 a, b만 학습 폴드에서 추정해 검증 폴드에서 평가(out-of-fold).
- 신뢰구간: 사용자 단위 cluster bootstrap, 사용자를 복원추출(278명씩) 2000회, seed 42, 뽑힌 사용자의 모든 기준 시점 유지, 모든 방법에 같은 추출(쌍대), 백분위 95% CI. 사용자 평균 MAE = 사용자별 MAE의 동일 가중 평균(주 지표), 풀링 MAE = 기준 시점 전체 평균(보조).
- 방향 밴드 ±10초: y ≤ −10 개선, −10 < y < 10 변화 없음, y ≥ 10 악화(ŷ도 같은 규칙).
- 환경: numpy 2.5.3, pandas 3.0.6, scipy 1.18.1 (B2 LAD는 `scipy.optimize.linprog`, HiGHS).

## 1. 정답 y 요약 (train 평가 대상, 분포 요약까지만)

| 개수 | 사용자 | 중앙값(초) | 25% 분위(초) | 75% 분위(초) |
|---|---|---|---|---|
| 1,720 | 278 | -2.7 | -108.5 | 104.9 |

| 방향 | 개수 | 비율 |
|---|---|---|
| 개선 | 825 | 48.0% |
| 변화 없음 | 109 | 6.3% |
| 악화 | 786 | 45.7% |

y = T5(정답 세션) − T5(기준 기록), 음수 = 개선. 한 사용자의 여러 기준 시점은 28일 입력 창이 겹칠 수 있어 서로 독립이 아니다.

## 2. 기준치별 지표 (95% CI)

| 기준치 | 사용자 평균 MAE(주) | 풀링 MAE | 방향 일치율 풀링 | 방향 일치율 사용자 평균 |
|---|---|---|---|---|
| B0 (ŷ=0) | 243.423 [208.788, 287.382] | 218.647 [184.917, 257.171] | 0.063 [0.049, 0.077] | 0.056 [0.039, 0.077] |
| B1 (ŷ=m−T5(기준)) | 211.109 [179.106, 255.116] | 186.128 [157.564, 219.157] | 0.558 [0.530, 0.581] | 0.505 [0.466, 0.544] |
| B2 (a+b×(T5(기준)−m), LAD) | 209.263 [177.736, 252.601] | 182.934 [154.732, 215.761] | 0.593 [0.568, 0.617] | 0.591 [0.552, 0.630] |

방향 일치율은 y와 ŷ를 같은 3범주 규칙으로 분류했을 때 같은 범주인 비율이다. B0은 항상 "변화 없음"이므로 일치율 = 변화 없음 범주의 비율이다. CI 구간이 겹친다고 같다는 뜻이 아니며(비교는 아래 쌍대 차이), CI가 0을 포함한 차이는 동등성의 증명이 아니다.

## 3. 기준치 간 쌍대 차이 (같은 기준 시점·같은 bootstrap 추출)

| 차이(앞 − 뒤) | 사용자 평균 MAE 차이(초) | 풀링 MAE 차이(초) | CI 상한 < 0 (앞이 더 낮은 사용자 평균 MAE) |
|---|---|---|---|
| B1 − B0 | -32.314 [-49.094, -16.679] | -32.520 [-45.886, -20.218] | 예 |
| B2 − B0 | -34.161 [-47.909, -21.789] | -35.714 [-47.569, -25.244] | 예 |
| B2 − B1 | -1.846 [-6.173, 2.380] | -3.194 [-6.025, -0.201] | 아니오 |

차이 = 앞 기준치의 MAE − 뒤 기준치의 MAE. 음수면 앞 기준치의 오차가 더 작다. 통계적 통과 기준(CI 상한 < 0)과 실용 기준(점추정 개선 ≥ 10초)은 모델 평가 단계에서 "모델 vs 최고 기준치"에 적용하며, 여기서는 기준치끼리의 차이를 기술적으로만 보고한다.
