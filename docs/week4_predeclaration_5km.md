# 5km 과제 사전 선언 (초안 — 확정 전, 결과 열람 없음)

작성: 10월 4주차(학기 8주차). 상태: **초안**. `[결정 필요]` 항목이 모두 정해지고 사용자가 승인한 뒤 11/1에 고정한다.
고정 이후에는 후보·지표·판정 기준을 결과를 본 뒤 바꾸지 않는다. 바꾸면 "탐색적 변경"으로 표시하고 원래 선언과 함께 보고한다.

이 문서를 쓰는 시점까지 **기록 변화(초)의 분포·평균·모델 오차는 계산하지 않았다.** 확인한 것은 개수뿐이다(`docs/week4_data_audit.md`).
개수 점검 중 모델 선택에 영향을 줄 수 있는 값(예: 다음 7일 5km 2회 이상 비율)은 아래 해당 결정 항목에 근거로만 적었다.

## 1. 연구 질문
지난 4주 동안 몇 번, 얼마나 멀리, 얼마나 쉬면서 달렸는지로 다음 7일 안 5km 기록 변화를 예측하고, 같은 사람 안에서 어떤 달리기 패턴 뒤에 기록이 좋아졌는지 본다. **상관관계까지만 주장한다(인과 아님).**

## 2. 정의
| 항목 | 정의 |
|---|---|
| 기준 시점 t | 매주 월요일 00:00. `start_time`(epoch 초)을 UTC로 해석해 만든 7일 격자. **UTC 여부는 미확인**이다(`docs/week4_data_audit.md` 6절 "판정 불가"). 격자 위치 영향은 민감도로 본다. |
| 5km 달리기 | 한 번 달린 거리(`actual_distance_km`)가 4.5~5.5km인 세션 1회. 병합 후 세션 단위. |
| 입력 구간 | 직전 28일: t−28일 ≤ 세션 종료 시각 < t (종료 = start_time + duration_sec). t 시점에 끝나지 않은 세션은 입력 금지. |
| 타깃 구간 | 다음 7일: 세션 시작 시각 ∈ [t, t+7일). |
| 평가 대상 자격 | 직전 28일 달리기 4회 이상 + 그중 5km 1회 이상 + 다음 7일 5km 1회 이상. |
| 기준 기록 | 직전 28일 안 가장 최근 5km 세션의 완주 시간(경과 시간 `duration_sec`, 초). |
| 정답 | 다음 7일 안 **[결정 필요: D1]** 5km 세션의 완주 시간 − 기준 기록 (초). 음수 = 빨라짐. |
| 입력 변수 | 직전 28일 달리기 횟수, 총 거리, 주별 거리 4개(t−28~−21, −21~−14, −14~−7, −7~0일; 종료 시각 기준), 가장 긴 거리, 마지막 달린 뒤 일수((t − 마지막 입력 세션 종료)/86,400초), 평균 심박. **[결정 필요: D2 평균 페이스, D3 성별, D4 기준 기록 자체]** |
| 누수 규칙 | 모든 행에 `last_input_session_time < t ≤ 타깃 세션 시작`을 assert. 타깃 세션의 거리·시간·심박·페이스는 입력 금지. 정규화·결측 처리는 허용된 학습 자료로만 fit(`ridge_lib`). |

## 3. 기준치(비교 대상)와 모델
- 기준치 1, **변화 없음**: 예측 0초(다음 5km 기록 = 기준 기록).
- 기준치 2, **평균 회귀**: **[결정 필요: D5 구체 식과 계수 추정]**
- 모델: Ridge(`ridge_lib`), GBM(`gbt_lib`), MLP(torch). 하이퍼파라미터는 train 사용자 내 GroupKFold(사용자 단위)로만 고른다. **[결정 필요: D9 탐색 격자]**
- 모델 선택에 테스트 점수를 쓰지 않는다. sklearn은 쓰지 않는다.

## 4. 분할과 평가
- cold-start: 기존 분할 파일(`data/train_user_ids.txt`, `data/test_user_ids.txt`) 재사용. 허용 학습 자료 = train 사용자의 기록뿐. (정의: 학습에 없던 사용자이지만 타깃 이전 기록이 있는 조건.)
- personalized: **[결정 필요: D6 시간 분할 규칙]**. 허용 학습 자료 = 각 사용자의 history 구간.
- 주 지표: **사용자 평균 MAE**(사용자별 MAE의 평균, macro). 보조: 풀링 MAE(기준 시점 평균).
- 신뢰구간: 사용자 단위 cluster bootstrap 2,000회, seed 42, 뽑힌 사용자의 모든 기준 시점과 모델별 예측 쌍 유지(쌍별 차이). 사용자 수·기준 시점 수·**평가 포함 비율**(전체 기준 시점 대비 평가 대상 비율, 사용자 기준 비율도)을 함께 적는다.
- 테스트는 **1회**만 본다(계획 11/15). 그 전에는 train 내부 CV만 쓴다.
- MAE와 RMSE를 모두 보고한다(RMSE는 보조).
- 참고 개수(`docs/week4_data_audit.md` 4절, 결과값 아님): 평가 대상 기준 시점은 전체 4,362개(470명), train 3,541개(379명), test 821개(91명). 같은 사용자의 기준 시점은 28일 입력 창이 겹쳐 독립이 아니므로 사용자 단위로 재표집한다.

## 5. 통과 기준
- 가장 좋은 기준치(변화 없음·평균 회귀 중 train에서 MAE가 낮은 것을 미리 정한 규칙으로 선택 — 테스트 점수로 고르지 않음) 대비 사용자 평균 MAE 개선(기준치 − 모델)의 **95% CI가 0을 제외할 때만** "넘는다"고 쓴다.
- 실용 기준: **[결정 필요: D7]**
- CI가 0을 포함하면 "구분되지 않음"이며 동등성 증명이 아니다.

## 6. 극단 기록
**[결정 필요: D8]** 기준 기록 또는 정답 세션의 페이스가 1,000초/km를 넘는 경우의 처리. 어떤 규칙을 쓰든 원래 평가 집합 결과는 유지하고, 제외 결과는 **사후 민감도로만** 보고한다.

## 7. 같은 사람 분석 (상관관계만)
- 사람별 평균을 뺀 회귀(within-user, 고정효과): 정답(기록 변화)과 입력 변수 모두에서 사용자별 평균을 뺀 뒤 회귀. 계수는 "같은 사람이 평소보다 더/덜 달렸을 때의 연관"이며 인과가 아니다. 사용자 단위 bootstrap CI.
- 보조 분석(쉰 날수): `docs/week4_data_audit.md` 5-c의 정의와 구간 [0,7) / [7,14) / [14,28) / [28,56) / 56일 이상. 연속된 5km 쌍 중 사이에 다른 달리기 세션이 없는 쌍만 쓴다. 2개 이상 구간에 쌍을 가진 사용자가 전체 156명(`week4_data_audit.md`)이라 사람 안 비교가 가능한 표본이 작다는 한계를 같이 적는다.
- 휴식·훈련 목적·대회 등 원본에 없는 정보는 설명 변수로 쓰지 않으며 "확인 불가"로 둔다.

## 8. 민감도 (사전 선언)
1. 5km 범위 4.8~5.2km.
2. 극단 기록 제외(D8과 별개의 사후 민감도).
3. 기준 시점 이동: 격자 시작 요일 0~6일 이동(시각 기준 미확인의 영향 확인).
4. (선택) 정답을 "첫 번째 5km" 대신 다른 규칙으로 바꾼 경우(D1).

## 9. 결정 필요 항목 (임의로 정하지 않음)

**D1. 다음 7일에 5km가 2회 이상일 때 정답으로 쓸 세션**
- 근거 개수: 평가 대상 기준 시점 중 다음 7일 5km가 2회 이상인 비율은 전체 22.9%(998/4,362), train 24.3%, test 16.7%.
- 선택지: (a) 첫 번째 5km — 규칙이 단순하고 t에 가까워 입력과 시간 간격이 일정, 이후 세션 정보를 쓰지 않음. 단 기준 기록과 간격이 짧은 쪽으로 치우칠 수 있음. (b) 마지막 5km — 7일 안 변화를 더 길게 보나 t에서 멀어 간격이 들쭉날쭉. (c) 7일 안 5km 평균 — 잡음 감소, 단 정답이 "한 번의 기록"이 아니게 되고 5km 횟수에 따라 분산이 달라짐.
- 초안 의견(미확정): (a)를 메인, (c)를 민감도.

**D2. 평균 페이스를 입력에 포함할지**
- (a) 포함 — 정보량 증가. 그러나 총 거리·횟수·기준 기록과 중복되고 극단 세션에 취약. (b) 제외 — 입력이 "훈련량·빈도"로 한정돼 연구 질문(몇 번, 얼마나, 얼마나 쉬면서)과 일치하나 현재 속도 수준 정보가 빠짐. (c) 직전 28일 5km 평균 페이스만 포함 — 기준 기록과 거의 같아 중복 위험.

**D3. 성별 포함 여부**
- 분포: 남 91.40% / 여 8.00% / unknown 0.60%(`week4_data_audit.md` 2절). (a) 포함 — 정보 있음, 단 여성·unknown 표본이 작아 계수 불안정. (b) 제외 — 단순하고 같은 사람 분석(사람 평균 제거)에서는 어차피 상쇄됨. (c) 모델 입력에는 제외, 층별 보고만.

**D4. 기준 기록(초) 자체를 입력에 포함할지**
- 정답이 "기록 − 기준 기록"이라 기준 기록이 낮은/높은 정도가 평균 회귀 신호를 담는다. (a) 포함 — 평균 회귀를 모델이 학습할 수 있으나 기준치 2와 정보가 겹쳐 모델이 기준치를 이긴 것이 새 정보인지 불명확. (b) 제외 — 훈련 변수만의 기여를 보지만 평균 회귀 기준치가 사실상 유리. (c) 두 변형을 모두 사전 선언하고 둘 다 보고.

**D5. 평균 회귀 기준치의 식과 학습 사용자에서의 계수 추정**
- 초안 식: 예측 Δ̂ = α·(μ − 기준 기록). μ와 α 선택 필요.
- μ 선택지: (i) 사용자의 t 이전 전체 5km 기록 평균(기준 기록 포함) — 사용자 특화, 5km 기록이 적으면 불안정. (ii) 직전 28일 5km 기록 평균 — 5km가 1개뿐이면 μ = 기준 기록이라 신호 없음. (iii) 학습 사용자 전체의 5km 기록 평균 — 단순하나 사람 간 수준 차이를 평균 회귀로 오인.
- α 추정 선택지(train 사용자의 평가 대상 기준 시점에서만): (A) 원점 통과 최소제곱 α = Σ(μ−ref)Δ / Σ(μ−ref)², 단순하나 극단 기록에 민감. (B) 절대오차(MAE) 최소화 — 평가 지표와 일치, 해가 수치적으로 구해짐. (C) 사용자 단위 GroupKFold로 α 선택 — 과적합 점검 가능, 구현 복잡. 학습에 쓴 기준 시점과 평가 기준 시점이 겹치지 않아야 한다.
- 초안 의견(미확정): μ = (i), α = (B).

**D6. personalized 시간 분할 규칙**
- 학습 기준 시점의 타깃 7일이 학습 종료 시점 안에 들어오게 해야 한다(타깃 정보 누수 방지).
- 선택지: (a) 사용자별 첫~마지막 달리기 시각을 기준으로 앞 80% 시점을 cut으로, 학습 기준 시점은 t+7일 ≤ cut, 테스트 기준 시점은 t ≥ cut (3주차와 같은 80/20 정신, 사용자마다 구간이 달라짐). (b) 전 사용자 공통 달력 시점 cut — 시간대 효과 통제, 사용자별 표본 수 불균형. (c) 사용자별 평가 대상 기준 시점의 앞 80%/뒤 20% — 표본 수 보장, 28일 입력 창이 cut에 걸쳐 history와 hold-out이 겹침(입력 창이 과거라 누수는 아니나 경계 처리 필요). 어느 쪽이든 입력 28일 구간이 cut 이전 세션만 쓰는지 assert로 확인하고, history/hold-out 경계에 걸친 세션 수를 보고한다.

**D7. 실용 기준(초)**
- 통계적으로 0을 제외해도 개선폭이 작을 수 있다. (a) 실용 기준 없음(CI만) — 결과를 보기 전 기준이 단순. (b) 고정 초 값(예: 5초) — 해석 쉬움, 값 선택의 근거 필요. (c) 기준치 MAE의 일정 비율(예: 5%) — 기록 수준에 비례, 비율 근거 필요. 어떤 값도 사전에 고정하며 CI 하한과 비교한다. 이전 과제(페이스 예측)의 개선폭은 근거로 쓰지 않는다(과제가 다름).

**D8. 극단 기록(페이스 1,000초/km 초과) 처리**
- 5km 세션에서 1,000초/km 초과는 5km 완주 시간 5,000초 초과에 해당한다. (a) 유지(메인), 제외는 사후 민감도 — 원래 평가 집합 보존, 지표가 극단값에 좌우될 수 있음. (b) 기준 기록 또는 정답이 극단이면 자격에서 제외(메인) — 지표 안정, 단 선택 편향과 평가 포함 비율 감소; 제외 건수를 보고. (c) 값을 상한으로 자르기(winsorize) — 표본 보존, 임의 상한 필요. 어느 쪽이든 극단 기록이 몇 개 기준 시점에 관여하는지 개수를 먼저 보고한다.

**D9. 하이퍼파라미터 탐색 격자**
- 기존 `docs/tree_results.md`, `docs/mlp_results.md`, `ridge_lib` 격자를 그대로 재사용(비교 일관성, 단 표본이 4천 개 수준이라 과대일 수 있음)할지, 표본 수에 맞춰 축소한 새 격자를 사전 고정할지. 고정할 격자를 확정 전에 이 문서에 적는다.

## 11. 한계 (미리 적음)
- `start_time`의 시각 기준이 미확인이라 월요일 00:00 격자와 "주" 경계의 의미가 불확실하다.
- 평가 대상은 "다음 7일에 5km를 달린 경우"로 조건부이며 선택 편향이 있다(달리지 않은 주는 평가되지 않음).
- 5km 세션이 있는 사용자만 대상이며 사용자 수가 작아(평가 대상 470명, test 91명) CI가 넓을 수 있다.
- 훈련 유형·대회·부상·날씨는 원본에 없어 해석에 쓸 수 없다. 상관관계 결과는 인과로 읽지 않는다.
