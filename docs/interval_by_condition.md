# 보고용 정리 표 2: 조건별 명목 80% 범위 포함률 + 분할 구분 확인

생성: `scripts/58_interval_by_condition_5km.py`. 새 학습·새 분석 없이 사후 분석 `scripts/56_b2_failure_5km.py`(사양 `docs/posthoc_spec_b2_failure_5km.md`, 커밋 f5ba594)의 층 정의·자료·bootstrap을 그대로 불러 와 보고용 열을 맞췄다. 층 경계는 결과를 본 뒤 바꾸지 않았고, **범위를 좁히거나 바꾸지 않는다**(시연의 B2 식·파라미터·범위 불변). 관측 수·사용자 수·포함률·CI가 `docs/b2_failure_5km.md`의 값과 같음을 assert로 확인했다. 시각은 start_time 원값(기준 미확인)이며 상관관계까지만 주장한다. 모든 평가는 "다음 7일 안에 적격 5km 기록이 관측된 경우"에 조건부다. ID·행 값은 싣지 않았다.

## 0. 먼저 읽을 것

- **39.1%(정지 300초 초과, train 폴드 밖)**: 관측 **87개**, 사용자 **45명**, 포함률 39.1% [28.7%, 49.2%], 평가 대상이 1개뿐인 사용자 30명. 같은 층의 test cold-start(탐색, 이미 열람): 관측 18개, 사용자 11명, 포함률 38.9% [15.4%, 61.1%] — 평가 대상 30개 미만이라 표본 부족으로 해석하지 않는다. 관측 수가 적은 층이고, 한 사용자의 여러 기준 시점이 함께 들어 있을 수 있다.
- **현재 범위는 고정 폭**(ŷ + [-202.1, +277.9]초 = 폭 480.0초)이라 모든 조건에서 **평균 폭이 같다**. 표의 "평균 폭" 열은 모두 480.0초이고, 조건별로 폭을 바꾸는 규칙은 없다.
- **개발 결과 vs 탐색 결과**: train 폴드 밖 열은 범위·조건별 안내 4개 층을 정하는 데 쓴 **개발 결과**이고, test cold-start 열은 이미 열람한 자료의 **탐색 결과**다(새 자료가 아니다).
- **시연의 조건별 안내 4개 층**(과거 유효 5km 1개, 2~4개, 직전 기록이 평소와 120초 넘게 차이, 직전 기록 세션 정지 300초 초과)은 train 폴드 밖 결과(평가 대상 30개 이상이고 포함률 95% CI 상한이 80% 미만)를 **보고 고른 개발 결과**이며, **새 자료로 확인되지 않았다.** 여러 층을 보고 고르므로 우연히 걸린 층이 있을 수 있다(다중 비교 보정 없음). 이 표는 안내 층이나 범위를 바꾸는 근거로 쓰지 않는다.
- 포함률 = 정답 y가 명목 80% 범위(ŷ + [q10_oof, q90_oof]) 안에 든 평가 대상의 비율(층 안 풀링). 95% CI는 사용자 단위 bootstrap(2,000회, seed 42, 층마다 그 층의 사용자를 복원추출). CI가 80%를 포함하면 "명목 80%에서 벗어났다고 확정할 수 없음"이고, 상한이 80% 미만일 때만 "명목 80%보다 낮음"이라고 쓴다. 관측 수 30개 미만은 표본 부족이다.
- "1개뿐 사용자" = 그 조건 안에서 평가 대상이 1개뿐인 사용자 수(그 사용자의 층 안 비율은 0% 또는 100%라 사용자별 해석에 한계가 있다).

### 4-3. 시연의 cold-start 범위를 personalized에 그대로 적용한 것은 맞는가

**판정: 분할 불일치가 있다(고치지 않고 보고한다).**

- 시연의 B2 a·b와 범위 분위수는 cold-start 자료(train 평가 대상 1,720개·278명 전체)에서 정했고 그 잔차는 사용자 단위 교차검증(학습에 없던 사용자)의 잔차다(4-1).
- personalized 평가 442개 중 **364개**(82.4%)가 시연의 a·b와 범위를 만든 train 평가 대상 1,720개에 **그대로 들어 있다**(평가 사용자 250명 중 201명이 train 사용자). 따라서 `docs/interval_calibration_5km.md`·`docs/demo_interval_check.md`의 personalized 포함률은 학습 자료와 독립이 아니다(55번도 같은 한계를 적었다).
- 최종 평가(49c02f8)의 personalized B2는 `p_tr` 적합(a = -15.881, b = -0.7807)이지만, 범위 포함률 점검의 personalized 열은 시연의 cold-start 적합(a = -15.287, b = -0.7912)으로 ŷ를 만들었다. 같은 "personalized"라는 이름 아래 B2가 두 가지다.
- personalized 조건에 맞는 범위를 따로 정하려면 사용자 안 시간순 분할로 잔차를 모아야 한다. **이번 정리에서는 계산하지 않았고**(새 분석·새 사양 필요), 시연 범위도 바꾸지 않았다. cold-start 열의 포함률은 이 불일치의 영향을 받지 않는다.
