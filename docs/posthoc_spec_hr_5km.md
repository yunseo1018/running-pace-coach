# 사후 탐색 사양: 기준 기록 세션의 상대 심박 (분석 실행 전 고정)

작성: 11월 1주차. **이 문서는 분석을 실행하기 전에 고정하는 사양이며, 이 문서를 만드는 시점에 r과 정답 y의 관계, 모형 계수, r의 분포는 계산하지 않았다.** 주 결론은 커밋 49c02f8(최종 평가, 평가 동결 `freeze-5km-v1`)로 이미 확정됐고 이번 분석은 그것을 바꾸지 않는다.

- 분류: **사후 탐색**(test 정답을 본 뒤의 분석, `docs/posthoc_spec_5km.md`의 A와 같은 성격). 상관관계까지만 주장하며 인과·처방 해석을 하지 않는다.
- 표기 규칙: 시각은 "start_time 원값(기준 미확인)", 러닝 기록의 빈 구간은 "관측된 러닝 기록의 공백"이라고 쓴다. ID·좌표·행 단위 값은 출력·저장하지 않고 중간 산출물은 `data/`에만 둔다.
- 이 사양 작성 전에 본 심박 자료: 평가 대상의 기준 기록·정답 세션의 heart_rate 점 값 품질 집계(0·결측 점 비율, 30 미만·230 초과 비율, 평균 심박 사용 가능 개수)만 확인했다. 심박과 y·T5의 관계나 r은 계산하지 않았다.
- 정의에 명시되지 않은 사항은 아래 "해석 규칙(정의 보완)"의 가장 좁은 읽기를 적용하고 결과 보고에서 목록으로 제시한다. 그 밖의 판단이 필요하면 임의로 정하지 않고 멈춰서 보고한다.

## 1. 정의

- **h_base** = 기준 기록 세션의 `avg_heart_rate`. 세션 표의 값이며 30~230bpm 유효 점의 평균이다(`01_parse_run_sessions.py`의 `MIN_PLAUSIBLE_HR`·`MAX_PLAUSIBLE_HR`).
- **h_ref** = 기준 시점 t 이전에 끝난, 기준 기록을 제외한 본인의 유효 5km 세션 `avg_heart_rate`의 중앙값. 그런 세션이 없으면 **그 평가 대상은 제외**한다.
- **r = h_base − h_ref** (bpm). 양수 = 기준 기록 세션의 평균 심박이 본인의 다른 유효 5km 세션보다 높았음.
- **결과는 10bpm 단위로 보고**한다(아래 "10bpm 단위" 참고).
- 기준 시점 t, 기준 기록, 정답 y, m, T5(기준) − m은 `docs/predeclaration_5km_final.md`의 정의를 그대로 쓴다(데이터셋 `build_dataset`와 같은 값).

## 2. 모형 (43번 같은 사람 안 분석과 같은 고정효과 within OLS)

- **주 모형**: y ~ (T5(기준) − m) + r
- **보조 모형**: 주 모형 + (T5(기준) − m) × r (곱은 원 변수 값으로 만든 뒤 사용자 평균을 뺀다)
- 사용자 고정효과는 사용자별 평균을 빼는 within 변환으로 처리한다(상수항은 사라진다). `43_within_person_5km.py`의 `within_ols`와 같은 방식이다.
- 10bpm 단위: r은 bpm으로 만든 뒤 **r10 = r / 10**을 설명 변수로 써서 계수를 "r이 +10bpm 클 때"의 값으로 보고한다. 보조 모형의 곱 항은 (T5(기준) − m) × r10이며 계수는 "r이 +10bpm 클 때 (T5(기준) − m) 1초당 계수 γ의 변화"이다. T5(기준) − m은 1초 단위 그대로 둔다. y의 단위는 초이다.

## 3. 추정

- **bootstrap**: 사용자 단위, 2,000회, seed 42, 백분위 95% CI. 사용자를 복원추출하고 뽑힌 사용자의 모든 평가 대상을 유지하며 같은 사용자가 여러 번 뽑히면 각각 별개 고정효과로 취급한다(사용자별 충분통계를 더해 추정, 43번과 동일).
- **대상 범위는 43번과 동일**: 평가 대상 2,072개 중 평가 대상이 2개 이상인 사용자의 모든 평가 대상(train·test 모두; 43번 기준 250명·1,973개). 여기에서 h_ref가 없는 평가 대상을 제외한다.
- 제외 뒤 평가 대상이 1개만 남은 사용자는 within 변환에서 기여가 0이며 추가 제외하지 않는다(사용자 수에는 남긴다). 남은 평가 대상이 2개 이상인 사용자 수를 따로 보고한다.
- 주 분석 데이터셋이 49c02f8의 평가 행과 일치하는지(사용자·시점·정답) 43번과 같은 assert로 확인한다.

## 4. 보고 항목

1. 포함/제외 개수와 사람 수: 43번 대상 범위(평가 대상, 사용자) → h_ref 없음으로 제외된 개수(사용자) → 분석 표본(평가 대상, 사용자, 평가 대상 2개 이상 남은 사용자).
2. r의 분포(분석 표본): 중앙값과 IQR(25%·75% 분위수), bpm. 참고로 10bpm 단위 값도 표기한다.
3. 각 모형의 계수와 95% CI(초 단위):
   - 주 모형: (T5(기준) − m) 1초당 계수, r10(+10bpm당) 계수
   - 보조 모형: 위 두 계수와 (T5(기준) − m) × r10 계수
4. 각 CI가 0을 포함하는지 표시한다. 그 밖에 검정·순위·모델 비교는 하지 않는다.

## 5. 해석 규칙 (미리 고정)

- CI가 0을 포함하면 **"관계를 확인하지 못함"**이라고 쓴다. 관계가 없다는 증명(동등성)이 아니다.
- CI가 0을 포함하지 않아도 **상관이며 인과가 아니다**. "~하면 빨라진다", "심박을 ~하라" 같은 인과·처방 표현을 쓰지 않는다. 평균 심박은 기온·컨디션·센서·훈련 강도 등과 얽힐 수 있으며 이 중 어느 것도 확인하지 않았다("미확인").
- 모델이 둘이고 계수가 여럿이므로 우연히 CI가 0을 벗어나는 계수가 생길 수 있다고 함께 쓴다. 결과를 보고 모형·정의·범위를 바꾸지 않는다.
- **freeze-5km-v1 결과(`docs/final_results_5km.md`, 49c02f8)와 시연 예측식(`demo/b2_params.json`의 B2: a·b와 잔차 분위수, `demo/coach_demo.py`)은 바꾸지 않는다.** 이번 결과는 시연이나 최종 평가에 반영하지 않는다.

## 6. 해석 규칙 (정의 보완, 실행 전 고정)

1. **유효 5km 세션**: 비병합(`merged_count == 1`)이고 `actual_distance_km ∈ [5.0, 5.5]`인 5km 후보 가운데 극단이 아닌(T5 ≤ 5,000초) 세션. `m`을 만들 때 쓰는 "과거 비극단 5km 후보"와 같은 집합이다.
2. **t 이전**: 세션의 종료 시각 < t. 기준 기록 세션은 집합에서 뺀다. 창(28일) 길이 제한은 두지 않는다(`m`과 같은 "t 이전 전체").
3. **h_ref의 값**: 위 집합 세션들의 세션 표 `avg_heart_rate`의 중앙값(짝수 개이면 가운데 두 값의 평균).
4. **h_base의 범위**: 세션 전체 심박 평균이며 처음 5km 구간의 평균이 아니다. 기준 기록 세션은 5.0~5.5km 길이라 거의 같은 구간이라고 추정하지만 처음 5km만의 평균은 아니다.
5. **세션 표 avg_heart_rate 결측**: 01번 단계가 유효 심박이 없는 세션을 제외하므로 결측이 없다(`docs/week4_data_audit.md` 2절). 결측이 있으면 그 세션은 h_base·h_ref 계산에서 제외하고 개수를 보고한다.
6. **r10 변환**: r10 = r / 10. 표본 분포는 bpm 단위로 보고한다.
