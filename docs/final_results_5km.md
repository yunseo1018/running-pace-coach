# 5km 과제 최종 평가 결과 (cold-start test + personalized, 각 1회)

생성: `42_final_eval_5km.py`. 방법·목록·결론의 위계는 `docs/evaluation_freeze_5km.md`(커밋 f1857fb, 태그 `freeze-5km-v1`)에 평가 전에 고정했고 그대로 한 번 실행했다. 정의는 `docs/predeclaration_5km_final.md`(3fad402)·`docs/predeclaration_5km_addendum.md`(9fb0d8f), 하이퍼파라미터는 `docs/model_cv_results_5km.md`에 기록된 선택값(다시 고르지 않음). 시각은 start_time 원값(기준 미확인)이며 상관관계까지만 주장한다. 사용자/세션 ID·행 값은 싣지 않았다.

- **결론의 위계**: 주 결론 = 기본 입력 Ridge·GBM·MLP의 (모델 − B2) 3개 비교. 보조 = 추가 비교·기준치 간 비교·방향 일치율. 탐색적 = E-MLP 전부(주 결론에 쓰지 않음).
- **다중 비교 주의**: 표에 비교가 많아 우연히 CI가 0을 벗어나거나 통과 기준을 만족하는 항목이 생길 수 있다. 통과 판정은 주 결론 3개에만 적용한다.
- 판정: 통계적 통과 = 사용자 평균 MAE 차이(모델 − B2)의 95% CI 상한 < 0, 실용적 통과 = 점추정 개선 ≥ 10초. CI가 0을 포함한 차이는 동등성의 증명이 아니다.
- CI: 사용자 단위 cluster bootstrap(2000회, seed 42), 사용자를 복원추출하고 뽑힌 사용자의 모든 기준 시점을 유지, 모든 방법에 같은 추출(쌍대), 백분위 95% CI. 방향 밴드 ±10초.
- 환경: numpy 2.5.3, pandas 3.0.6, torch 2.14.0+cpu. 실행 후 추가 분석은 모두 "사후 분석"으로 표시한다(이 문서에는 없음).
- 학습 자료: cold-start = train 평가 대상 1,720개·278명, 평가 = test 352개·71명. personalized = 학습 1,531개, 평가 442개·250명(test 사용자 포함). 개수는 `docs/dataset_counts_5km.md`와 일치(assert).
