# 5km 과제 평가 동결 (freeze-5km-v1)

작성: 10월 5주차(학기 9주차). **test·personalized 평가를 실행하기 전에 작성·커밋하고 태그(`freeze-5km-v1`)를 붙인다.** 이 문서가 최종 평가 목록·방법·결론의 위계를 고정한다.
정의의 기준은 `docs/predeclaration_5km_final.md`(3fad402)와 `docs/predeclaration_5km_addendum.md`(9fb0d8f)이며, train 내부 모델 비교 결과는 `docs/model_cv_results_5km.md`(84670d6)다.
test 평가는 3단계에서 **정확히 1회만** 실행한다. 실행 후에는 모델·설정·정의를 바꾸지 않으며, 실행 후 추가 분석은 모두 "사후 분석"으로 표시한다.
이 시점까지 test 사용자의 정답 y와 T5 값은 계산하지 않았다(극단 판정 불리언만 개수 산출에 사용; `docs/results_viewed_log.md`). 시각은 start_time 원값(기준 미확인)이며 상관관계까지만 주장한다.

## 1. 탐색적 MLP (E-MLP) — "train 결과를 본 뒤 설정을 바꾼 탐색적 모델"
84670d6의 train 내부 결과에서 MLP가 모든 입력 세트·모든 폴드에서 에폭 상한(200)에 닿았고(학습 폴드 약 1,400행, 배치 2048이라 에폭당 갱신 1회), 이를 본 뒤 정한 변경이다. 따라서 **탐색적**이며 주 결론에 쓰지 않는다.
기존 MLP 구조 격자(hidden_layers∈{1,2} × width∈{32,64} × weight_decay∈{0,1e-4})는 그대로이고, 바꾸는 것은 세 가지뿐이다.
- 배치 크기 = 64 (기존 2048)
- 에폭 상한 = 1,000 (기존 200)
- 조기 종료 = 내부 검증(학습 폴드 사용자 20%, seed 42; `ridge_lib.group_kfold_indices(…, 5, 42)`의 첫 분할) 풀링 MAE가 **50에폭** 동안 개선되지 않으면 중단 (기존 15)
- 그 외 동일: 손실 `L1Loss`, Adam lr 1e-3, 입력 표준화는 학습 자료에서만 적합, seed 42 하나, 선택된 에폭 수로 학습 자료 전체를 다시 학습(27번과 같은 방식).
- 입력 세트 3가지: 기본(11), +평균 페이스(12), +성별 one-hot(14).
- 구조(격자) 선택은 40번과 같은 GroupKFold(5, seed 42) 폴드 밖 사용자 평균 MAE 최저이며, 선택 결과는 2단계 커밋(`docs/model_cv_results_5km.md` "탐색적" 절)에 기록된다. test 평가에는 그 기록된 구조를 그대로 쓴다.

## 2. 결론의 위계 (사전 지정)
- **주 결론** = 기본 입력 Ridge·GBM·MLP 3개 각각의 (모델 − B2) 비교만으로 내린다. 통과 판정은 이 3개에만 적용한다.
- **보조** = 추가 비교(+평균 페이스 − 기본, +성별 − 기본), 기준치 간 비교(B1−B0, B2−B0, B2−B1), 방향 일치율.
- **탐색적** = E-MLP 전부(E-MLP − B2 포함). 주 결론에 쓰지 않는다.
- 비교가 여러 개라 우연한 통과 가능성이 있다. 결과 문서에 다중 비교로 인한 우연 통과 가능성을 명시하고, 주 결론 3개 외의 통과는 "통과"로 요약하지 않는다.

## 3. 최종 평가 목록 (이 목록 밖은 평가하지 않는다)
1. 기준치: B0(ŷ=0), B1(ŷ=m−T5(기준 기록)), B2(ŷ=a+b×(T5(기준 기록)−m), LAD).
2. Ridge · GBM · MLP × {기본, +평균 페이스, +성별} = 9개. 하이퍼파라미터는 84670d6의 `docs/model_cv_results_5km.md` 1절에서 선택된 값(GroupKFold 폴드 밖 사용자 평균 MAE 최저)을 그대로 쓴다. MLP의 에폭 수는 아래 4·5항의 방식으로 학습 자료 안 내부 검증에서 정한다.
3. E-MLP × {기본, +평균 페이스, +성별} = 3개.

모델·손실은 기존 구현 그대로: Ridge(`ridge_lib`, 제곱오차+L2), GBM(`gbt_lib`, absolute_error), MLP(torch `L1Loss`), E-MLP(torch `L1Loss`, 위 설정). 타깃은 y(초) 그대로.

## 4. cold-start test 평가
- 학습: 모든 모델과 B2의 a·b를 **train 평가 대상 전체(1,720개·278명)**로 다시 학습·추정한다. 전처리(표준화)는 train에서만 적합한다.
- 평가: **test 평가 대상(352개·71명)**에 1회 적용한다(`docs/dataset_counts_5km.md`의 개수와 일치해야 하며 불일치하면 중단).
- MLP·E-MLP의 에폭 수: 학습 자료(1,720개) 안에서 사용자 20% 내부 검증(seed 42)으로 정한 뒤 학습 자료 전체로 재학습한다(CV 폴드 안에서 한 것과 같은 방식).

## 5. personalized 평가
- 학습 = personalized 학습 기준 시점(1,531개), 평가 = 442개(평가 대상 ≥2개인 250명; test 사용자 49명·78개 포함; `docs/dataset_counts_5km.md` 3절). 개수가 다르면 중단.
- 하이퍼파라미터는 cold-start CV에서 선택된 값을 그대로 쓰고 다시 고르지 않는다. B2의 a·b와 전처리는 personalized 학습분에서만 적합한다. MLP·E-MLP의 에폭 수는 personalized 학습분 안 사용자 20% 내부 검증으로 정한다.

## 6. 지표·판정
사전 선언 확정본(3fad402)과 보충(9fb0d8f) 그대로.
- 사용자 평균 MAE(주), 풀링 MAE, 방향 일치율(밴드 ±10초; 풀링·사용자 평균), 사용자 단위 bootstrap 2,000회(seed 42, 사용자를 복원추출하고 그 사용자의 모든 기준 시점 유지, 모든 방법에 같은 추출), 백분위 95% CI, 같은 기준 시점 쌍대 차이.
- 통과 기준은 **모델 − B2**로 판정: 통계적 통과 = 사용자 평균 MAE 차이의 95% CI 상한 < 0, 실용적 통과 = 점추정 개선 ≥ 10초. 둘을 따로 보고한다. CI가 0을 포함하는 차이는 동등성의 증명이 아니다.
- 보고 표: (a) test 정답 y 요약(개수, 중앙값, 25/75% 분위, 개선/변화 없음/악화 비율), (b) 모든 평가 대상의 지표(95% CI), (c) 주 결론 표(기본 Ridge·GBM·MLP − B2), (d) 보조 표, (e) 탐색적 표(E-MLP − B2), (f) personalized의 같은 형식.

## 7. 실행 후 규칙
- test 실행 후의 추가 분석은 모두 "사후 분석"으로 표시하고, 위 목록·설정·정의를 바꾸지 않는다. 결과가 기대와 달라도 동결된 방법으로 보고한다.
- 최종 평가는 `42_final_eval_5km.py`로 한 번만 실행한다(재실행 방지 표식 파일 사용). 결과는 `docs/final_results_5km.md`다.
