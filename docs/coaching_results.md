# 코칭 1단계 + 코칭 평가 분리 (10월 2주차 10~11단계)

> **중요: 이 데이터에는 사용자가 입력한 실제 목표(목표 거리/페이스/데드라인)가 없다. 아래 모든 목표는 '합성 시나리오'이며, 실제 사용자 목표 기반 코칭 성능이 아니다.** 이 문서는 "예측 오차가 코칭 판정을 얼마나 흔드는가"만 본다. 시나리오(목표 비율 delta, 데드라인, 카테고리 임계값)는 모두 결과를 보기 전에 고정한 합성 설정이다.

입력 메인 데이터: `data\run_sessions_deduped_merged.pkl` (세션 105709건, 사용자 854명, assert 통과). 평가 윈도우는 7~9단계와 동일(24단계 확장 피처 윈도우), 모델은 9단계와 같은 하이퍼파라미터로 refit(재탐색 없음, 9단계 MAE와 일치하는지 assert로 확인).

## 0. 설계 (사전 고정 — 결과를 보고 바꾸지 않음)
- **합성 목표**: 현재 실력 = 윈도우의 median-5(과거 5세션만 사용), 목표 페이스 = 현재 실력 × (1−delta), delta ∈ {3%, 5%, 10%}, 데드라인 8주(민감도: 4주). 목표 거리는 문구 표시용(윈도우 과거 5세션 평균 거리)이며 판정에 쓰지 않는다.
- **주간 체크포인트**: 현재 실력에서 목표 페이스까지 주 단위 선형 보간. 타깃이 몇 주차인지는 ceil((타깃 시작 − 마지막 입력 세션 종료) / 7일)(최소 1)로 계산하고, **주차 > 데드라인 주수인 윈도우는 제외**하며 제외 비율을 보고한다.
- **격차** = 예측 페이스 − 해당 주차 체크포인트 (초/km, 양수 = 뒤처짐).
- **카테고리(격차 ÷ 현재 페이스)**: 앞서감(≤ −3%), 계획대로(−3% 초과 ~ +3%), 조금 뒤처짐(+3% 초과 ~ +10%), 크게 뒤처짐(+10% 초과). **임계값은 설계값이며 튜닝하지 않았다.**
- **고정 템플릿**: 카테고리별 3개 문구(coaching_lib.py), LLM/RAG 사용 없음. 코칭 모듈(coaching_lib.py)은 모델을 import하지 않는 별도 모듈이다.
- **예측기**: median-5 / 전체 이력 중앙값 / 0.5×median-5+0.5×전체 이력 중앙값 / 직접구현 GBM / MLP. 후자 둘은 CV·검증 선택 모델(cold-start: GBM=absolute_error 직접, personalized: median5+잔차, MLP는 둘 다 median5+잔차). 전체 이력 중앙값·블렌드는 9단계에서 ablation을 본 뒤 추가한 사후 baseline이다.

## 요약 (delta 5%, 데드라인 8주 기준; 모든 수치는 합성 시나리오)
- 판정 불일치율(실제 페이스로 판정한 카테고리와 다른 비율)은 median-5 예측기를 제외하면 62~67% 범위다(8주·delta 5% 기준). 예측 오차(MAE 약 55~60초/km)에 비해 주당 체크포인트 이동(약 2초/km)이 매우 작아 판정은 예측 오차와 러닝 간 변동에 지배된다(5절).
- cold-start: 상수 규칙 65.2%, 전체이력중앙값 63.2%, GBM 64.6%, MLP 65.9%.
  - 상수 규칙 − 직접구현 GBM: +0.58%p (95% CI [-1.82, +3.38], 0 포함)
  - 상수 규칙 − MLP: -0.70%p (95% CI [-3.14, +2.11], 0 포함)
  - 전체이력중앙값 − 직접구현 GBM: -1.41%p (95% CI [-2.52, -0.18], 0 불포함)
  - 전체이력중앙값 − MLP: -2.69%p (95% CI [-3.80, -1.48], 0 불포함)
- personalized: 상수 규칙 66.9%, 전체이력중앙값 62.6%, GBM 62.8%, MLP 63.3%.
  - 상수 규칙 − 직접구현 GBM: +4.13%p (95% CI [+2.43, +5.95], 0 불포함)
  - 상수 규칙 − MLP: +3.59%p (95% CI [+1.93, +5.38], 0 불포함)
  - 전체이력중앙값 − 직접구현 GBM: -0.22%p (95% CI [-1.17, +0.75], 0 포함)
  - 전체이력중앙값 − MLP: -0.75%p (95% CI [-1.62, +0.16], 0 포함)
- median-5 예측기 대비 비교는 현재 실력을 median-5로 정의한 시나리오의 구조 효과(3-5절)가 커서 요약에 쓰지 않는다.

## 3. 코칭 판정 불일치율 (실제 페이스로 판정한 카테고리 vs 예측 페이스로 판정한 카테고리) — 합성 시나리오
불일치율 = 같은 윈도우에서 두 카테고리가 다른 비율. 같은 체크포인트·같은 현재 페이스를 쓰므로 불일치는 오직 (예측−실제) 페이스 차이가 카테고리 경계를 넘나드는 정도로 결정된다. **상수 규칙** = 항상 같은 카테고리 하나만 말하는 규칙. **그 카테고리는 평가 데이터가 아니라 허용된 학습 자료에서 정한다** (코드: `train_ref_info`): cold-start는 train 사용자 윈도우, personalized는 history 구간 윈도우에서, 같은 delta·데드라인 설정으로 실제 페이스 기준 참조 카테고리의 최빈값을 구해 평가 구간에 그대로 적용한다. (이전 버전은 평가 세트에서 최빈값을 골랐으나 그것은 평가 데이터를 쓰는 것이라 이 버전에서 학습/이력 구간 기준으로 바꿔 다시 계산했다.) CI는 사용자 단위 bootstrap 95%.

## 6. 한계
- 목표는 전부 합성이다: 실제 사용자의 목표 설정 방식, 목표 달성 여부, 코칭 문구에 대한 반응은 관찰하지 않았다(미확인).
- 현재 실력을 median-5로 정의했으므로 median-5 예측기는 '예측 = 현재 실력'이라 격차가 체크포인트 이동폭(최대 delta)에 의해서만 결정된다 — median-5 예측기의 불일치율에는 이 정의가 구조적으로 영향을 준다(다른 예측기와 대칭이 아님).
- 데드라인 초과 윈도우 제외로 표본이 달라지고(2절), 4주/8주 결과는 서로 다른 표본 위에서 계산된다.
- 불일치율 CI는 사용자 단위 bootstrap이며 모델 재학습 변동성은 반영하지 않는다(GBM은 결정적, MLP는 시드 1개 사용).
- 코칭 문구의 품질(자연스러움, 근거 일치)은 평가하지 않았다. RAG·LLM 평가는 이 단계 범위 밖이다.

### 향후 과제 (가설, 이번에 검증하지 않음)
- 러닝 한 번의 페이스는 변동이 커서(5절) 단일 세션 페이스를 예측해 카테고리를 판정하는 방식보다, 여러 세션을 집계한 지표(예: 최근 몇 주 평균/중앙값 추세)를 기반으로 한 코칭이 더 적합할 수 있다. 이는 가설이며 이번 단계에서는 어떤 분석도 하지 않았다.
