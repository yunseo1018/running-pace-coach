# 극단 세션 ↔ 윈도우 대응 (10월 3주차 5번)

> **세션 단위 비율 0.781%(극단 세션 826건 / 정제 세션 105,709건)와 윈도우 단위 기여(제곱오차 상위 1% 윈도우의 SSE 비중 92~93%)는 집계 단위가 다르다.** 한 세션은 타깃으로 1개 윈도우, 입력으로 최대 5개 윈도우에 등장하므로 세션 비율을 윈도우 비율로 바로 옮길 수 없고, 상위 1% 윈도우의 SSE 비중은 세션이 아니라 윈도우 단위 제곱오차의 집중도다. 이 문서의 모든 서술은 **관찰**이며 인과 해석을 하지 않는다. 극단 페이스가 GPS 오류인지 실제 휴식 포함인지는 검증하지 않았다(미확인). 분류 규칙·임계값은 `week3_predeclaration.md` 9절에 데이터를 보기 전에 고정했다. 사용자 ID·세션 ID는 문서에 쓰지 않으며 세션 단위 표는 `data/`(git 제외)에만 저장했다.

## 1. 극단 세션과 분류 규칙
- 극단 세션 = 경과 시간 기준 평균 페이스 > 1000초/km. 정제 세션 105,709건 중 **826건(0.781%)** — 기존 `docs/target_pace_definition.md`와 일치(사전 선언 9-1의 중단 조건 통과).
- 분류 규칙(세션 표의 열로 가능한 것만, 사전 고정): (a) `merged_count>1`, (b) 정지 비율 `gap_ratio≥0.5`, (c) `actual_distance_km<1`, (d) 위 어디에도 해당 없음. **한 세션이 (a)~(c) 여러 범주에 해당하면 각각 중복 집계**한다((a)~(c) 합이 세션 수보다 클 수 있음).
- **GPS 오류·중복 흔적은 '미판정'**: 포인트 단위 정보는 01단계에서 이미 필터링되었고 중복은 16단계에서 제거된 세션만 남아 있어 세션 표만으로는 판정할 수 없다(원본 재파싱은 하지 않았다). 따라서 (d) 미분류는 'GPS 오류나 중복이 아님'을 뜻하지 않는다.

## 6. 관찰과 한계
- 위 모든 수치는 관찰이며 인과 해석을 하지 않는다. 극단 윈도우를 제외한 결과는 '극단 페이스 윈도우가 지표에 얼마나 관여하는가'를 보는 민감도이지, 그 윈도우가 오류라는 판정이 아니다.
- 세션 표만으로 GPS 오류·중복 흔적을 판정할 수 없어 '미판정'으로 남겼다. (a)~(c) 분류는 정의된 열에 의한 단순 규칙이며 임계값(`gap_ratio≥0.5`, `<1km`)은 사전 고정값이다. 다른 임계값에서의 분포는 보지 않았다.
- 경과 시간 기준 페이스가 큰 세션을 체력 저하나 목표 실패로 해석하지 않는다(휴식·훈련 목적·워치를 켜둔 채 쉰 시간 등이 포함될 수 있음).
