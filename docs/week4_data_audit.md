# 10월 4주차(8주차) 데이터 점검 기록 (5km 과제 준비)

생성: `35_data_audit_5km.py` (읽기 전용·개수만). 시각 기준 점검은 `36_timezone_check.py`가 아래 TZ 블록에 기록한다.
**기록 변화(초) 등 결과값의 분포·평균은 계산하지 않았다(사전 선언 전 결과 열람 금지). 실제 행 값·ID·좌표는 싣지 않았다.**

기준 시점 t는 `start_time`(epoch 초)을 UTC로 가정한 월요일 00:00의 7일 격자이며, 이 가정은 미확인이다(TZ 블록 참고). 입력 구간은 t−28일 ≤ end_time < t(end_time = start_time + duration_sec), 타깃 구간은 시작 시각 ∈ [t, t+7일)이다. 5km 세션은 한 번 달린 거리가 4.5~5.5km인 세션 1회다.
